# Rychlý přepínač oken na aktuální ploše pro COSMIC (`cosmic-ws-switcher` v0.2.0)

Tento nástroj přidává do prostředí **COSMIC Desktop (Pop!_OS)** bleskové cyklické přepínání oken pouze v rámci právě aktivní pracovní plochy (workspace) pomocí klávesových zkratek **`Super + ←`** (předchozí okno) a **`Super + →`** (další okno).

## Proč vzniklo toto řešení a jak funguje
Výchozí přepínání nebo volání jednorázových příkazů přes CLI nástroj `cosmicmsg` trvá při každém stisku klávesy přibližně **300 ms** (kvůli opakovanému navazování spojení s Waylandem a synchronizaci stavů). Navíc knihovní funkce `cosmicmsg::subscribe` trpí chybou při sledování ploch a ve vícevláknovém režimu způsobuje přeskakování fokusu zpět na staré okno (race condition).

**Architektura `v0.2.0` tyto problémy kompletně odstraňuje:**
* **Jediné trvalé Wayland spojení:** Daemon běží v jednom vlákně nad `libc::poll` a současně sleduje Wayland socket i lokální Unix socket (`$XDG_RUNTIME_DIR/cosmic-ws-switcher.sock`).
* **Okamžitá odezva (~0,15 až 0,25 ms):** Stav všech oken a ploch je neustále udržován v RAM (spotřeba ~1 MB). Při stisku zkratky se pouze odešle přímý Wayland požadavek `activate` + `flush()`.
* **Stabilní pořadí a Optimistic Lock:** Okna se řadí deterministicky podle pořadí otevření a po dobu 300 ms od stisku platí optimistický zámek, takže při zběsilém mačkání šipek nikdy nedojde k vrácení na předchozí okno.

use cosmicmsg::{collect_state, window_activate, AppData, EventQueue};
use std::{
    collections::HashSet,
    env, fs,
    io::{Read, Write},
    os::fd::{AsFd, AsRawFd},
    os::unix::net::{UnixListener, UnixStream},
    path::PathBuf,
    time::{Duration, Instant},
};

#[derive(Debug, Clone, Copy)]
enum Direction {
    Next,
    Prev,
}

struct Tracker {
    /// Stabilní pořadí oken podle toho, kdy vznikla (aby rotace nepřeskakovala tam a zpět)
    order: Vec<String>,
    /// Poslední známé aktivní okno z Waylandu
    wayland_active: Option<String>,
    /// Optimisticky vybrané okno při rychlém mačkání kláves (ochrana před race condition)
    optimistic_target: Option<(String, Instant)>,
    /// Statistiky posledního přepnutí v mikrosekundách
    last_select_us: u128,
    last_activate_us: u128,
    total_switches: u64,
}

impl Tracker {
    fn new() -> Self {
        Self {
            order: Vec::new(),
            wayland_active: None,
            optimistic_target: None,
            last_select_us: 0,
            last_activate_us: 0,
            total_switches: 0,
        }
    }

    /// Synchronizuje naše stabilní pole `order` a `wayland_active` přímo z živého `AppData`
    fn sync_from_wayland(&mut self, app_data: &AppData) {
        let toplevels = app_data.toplevels();
        let mut current_ids = HashSet::with_capacity(toplevels.len());
        let mut newly_activated: Option<String> = None;

        for win in &toplevels {
            current_ids.insert(win.identifier.clone());
            if !self.order.contains(&win.identifier) {
                self.order.push(win.identifier.clone());
            }
            if win.state.iter().any(|s| s == "activated") {
                newly_activated = Some(win.identifier.clone());
            }
        }

        // Odstranit zavřená okna ze seznamu pořadí
        self.order.retain(|id| current_ids.contains(id));

        if let Some(act) = newly_activated {
            self.wayland_active = Some(act.clone());
            if let Some((ref opt_id, _)) = self.optimistic_target {
                if opt_id == &act {
                    self.optimistic_target = None;
                }
            }
        }
    }

    /// Zjistí, které okno považujeme v tento okamžik za výchozí pro další krok rotace
    fn effective_current(&mut self) -> Option<String> {
        if let Some((ref target, ts)) = self.optimistic_target {
            if ts.elapsed() < Duration::from_millis(300) && self.order.contains(target) {
                return Some(target.clone());
            }
            self.optimistic_target = None;
        }
        self.wayland_active.clone()
    }

    fn select(&mut self, app_data: &AppData, direction: Direction) -> Option<String> {
        self.sync_from_wayland(app_data);

        let workspaces = app_data.workspaces();
        let active_ws_names: HashSet<String> = workspaces
            .into_iter()
            .filter(|ws| ws.active)
            .map(|ws| ws.name)
            .collect();

        let toplevels = app_data.toplevels();
        let cur_id = self.effective_current();

        let target_ws = cur_id
            .as_ref()
            .and_then(|cid| toplevels.iter().find(|t| &t.identifier == cid))
            .and_then(|win| {
                win.workspaces
                    .iter()
                    .find(|ws| active_ws_names.contains(*ws))
                    .or_else(|| win.workspaces.first())
                    .cloned()
            })
            .or_else(|| active_ws_names.iter().next().cloned())?;

        let candidates: Vec<String> = self
            .order
            .iter()
            .filter(|id| {
                if let Some(win) = toplevels.iter().find(|t| &t.identifier == *id) {
                    let is_sticky = win.state.iter().any(|s| s == "sticky");
                    let on_ws = win.workspaces.iter().any(|ws| ws == &target_ws);
                    is_sticky || on_ws
                } else {
                    false
                }
            })
            .cloned()
            .collect();

        if candidates.len() <= 1 {
            return None;
        }

        let current_index = cur_id
            .as_ref()
            .and_then(|cid| candidates.iter().position(|id| id == cid));

        let next_index = match (direction, current_index) {
            (Direction::Next, Some(i)) => (i + 1) % candidates.len(),
            (Direction::Prev, Some(i)) => {
                if i == 0 {
                    candidates.len() - 1
                } else {
                    i - 1
                }
            }
            (Direction::Next, None) => 0,
            (Direction::Prev, None) => candidates.len() - 1,
        };

        let chosen = candidates[next_index].clone();
        self.optimistic_target = Some((chosen.clone(), Instant::now()));
        Some(chosen)
    }
}

fn socket_path() -> PathBuf {
    if let Ok(runtime) = env::var("XDG_RUNTIME_DIR") {
        PathBuf::from(runtime).join("cosmic-ws-switcher.sock")
    } else {
        PathBuf::from(format!("/tmp/cosmic-ws-switcher-{}.sock", unsafe {
            libc::getuid()
        }))
    }
}

/// Přečte všechny čekající události z Wayland socketu bez blokování
fn pump_wayland(
    app_data: &mut AppData,
    eq: &mut EventQueue<AppData>,
    tracker: &mut Tracker,
) -> Result<(), String> {
    let _ = eq.flush();
    if let Some(guard) = eq.prepare_read() {
        match guard.read() {
            Ok(_) => {}
            Err(wayland_client::backend::WaylandError::Io(ref e))
                if e.kind() == std::io::ErrorKind::WouldBlock => {}
            Err(e) => return Err(format!("Wayland read error: {e}")),
        }
    }
    eq.dispatch_pending(app_data)
        .map_err(|e| format!("Wayland dispatch error: {e}"))?;
    tracker.sync_from_wayland(app_data);
    Ok(())
}

fn handle_client(
    mut stream: UnixStream,
    app_data: &mut AppData,
    eq: &mut EventQueue<AppData>,
    tracker: &mut Tracker,
) {
    let mut buf = [0u8; 64];
    let n = match stream.read(&mut buf) {
        Ok(n) if n > 0 => n,
        _ => return,
    };
    let cmd = std::str::from_utf8(&buf[..n]).unwrap_or("").trim();

    match cmd {
        "next" | "prev" => {
            let dir = if cmd == "next" {
                Direction::Next
            } else {
                Direction::Prev
            };

            let t0 = Instant::now();
            let _ = pump_wayland(app_data, eq, tracker);
            let target = tracker.select(app_data, dir);
            let select_us = t0.elapsed().as_micros();

            if let Some(identifier) = target {
                let t1 = Instant::now();
                if let Err(e) = window_activate(app_data, eq, &identifier) {
                    eprintln!("Chyba pri aktivaci okna {identifier}: {e}");
                }
                let activate_us = t1.elapsed().as_micros();

                tracker.last_select_us = select_us;
                tracker.last_activate_us = activate_us;
                tracker.total_switches += 1;

                let _ = writeln!(
                    stream,
                    "ok target={} select_us={} activate_us={}",
                    identifier, select_us, activate_us
                );
            } else {
                let _ = writeln!(stream, "noop select_us={}", select_us);
            }
        }
        "ping" => {
            let _ = stream.write_all(b"pong\n");
        }
        "status" => {
            let _ = pump_wayland(app_data, eq, tracker);
            let toplevels = app_data.toplevels();
            let active_ws: Vec<String> = app_data
                .workspaces()
                .into_iter()
                .filter(|w| w.active)
                .map(|w| w.name)
                .collect();

            let _ = writeln!(
                stream,
                "windows={} wayland_active={:?} optimistic={:?} active_ws={:?} last_select_us={} last_activate_us={} total_switches={}",
                toplevels.len(),
                tracker.wayland_active,
                tracker.optimistic_target.as_ref().map(|(id, _)| id),
                active_ws,
                tracker.last_select_us,
                tracker.last_activate_us,
                tracker.total_switches
            );
            for (idx, id) in tracker.order.iter().enumerate() {
                if let Some(w) = toplevels.iter().find(|t| &t.identifier == id) {
                    let _ = writeln!(
                        stream,
                        "  [{}] id={} app={} ws={:?} state={:?} title={:?}",
                        idx, w.identifier, w.app_id, w.workspaces, w.state, w.title
                    );
                }
            }
        }
        other => {
            let _ = writeln!(stream, "err unknown command: {other}");
        }
    }
}

fn run_daemon() -> Result<(), Box<dyn std::error::Error>> {
    let sock = socket_path();
    if sock.exists() {
        let _ = fs::remove_file(&sock);
    }

    let (mut app_data, mut eq) = collect_state()?;
    let mut tracker = Tracker::new();
    tracker.sync_from_wayland(&app_data);

    let listener = UnixListener::bind(&sock)?;
    listener.set_nonblocking(true)?;

    let wl_fd = eq.as_fd().as_raw_fd();
    let sock_fd = listener.as_raw_fd();

    eprintln!(
        "cosmic-ws-switcher v0.2.0 daemon bezi na {} (oken: {})",
        sock.display(),
        tracker.order.len()
    );

    loop {
        let _ = eq.flush();

        let mut fds = [
            libc::pollfd {
                fd: wl_fd,
                events: libc::POLLIN,
                revents: 0,
            },
            libc::pollfd {
                fd: sock_fd,
                events: libc::POLLIN,
                revents: 0,
            },
        ];

        let ret = unsafe { libc::poll(fds.as_mut_ptr(), fds.len() as libc::nfds_t, -1) };
        if ret < 0 {
            let err = std::io::Error::last_os_error();
            if err.kind() == std::io::ErrorKind::Interrupted {
                continue;
            }
            return Err(Box::new(err));
        }

        if (fds[0].revents & (libc::POLLIN | libc::POLLERR | libc::POLLHUP)) != 0 {
            if let Err(e) = pump_wayland(&mut app_data, &mut eq, &mut tracker) {
                eprintln!("{e}");
                break;
            }
        }

        if (fds[1].revents & libc::POLLIN) != 0 {
            loop {
                match listener.accept() {
                    Ok((stream, _)) => {
                        handle_client(stream, &mut app_data, &mut eq, &mut tracker);
                    }
                    Err(ref e) if e.kind() == std::io::ErrorKind::WouldBlock => break,
                    Err(e) => {
                        eprintln!("Socket accept error: {e}");
                        break;
                    }
                }
            }
        }
    }

    Ok(())
}

fn send_command(command: &str, print_reply: bool) -> Result<(), Box<dyn std::error::Error>> {
    let sock = socket_path();
    let mut stream = UnixStream::connect(&sock)?;
    stream.write_all(command.as_bytes())?;
    stream.shutdown(std::net::Shutdown::Write)?;

    if print_reply {
        let mut response = String::new();
        stream.read_to_string(&mut response)?;
        print!("{response}");
    }
    Ok(())
}

fn run_bench() -> Result<(), Box<dyn std::error::Error>> {
    println!("=== Interni benchmark cosmic-ws-switcher v0.2.0 ===");
    send_command("status", true)?;
    println!("\nTestuji 10x prepnuti (5x next, 5x prev) s pauzou 80 ms...");

    for i in 1..=10 {
        let cmd = if i <= 5 { "next" } else { "prev" };
        let t0 = Instant::now();
        let sock = socket_path();
        let mut stream = UnixStream::connect(&sock)?;
        stream.write_all(cmd.as_bytes())?;
        stream.shutdown(std::net::Shutdown::Write)?;

        let mut reply = String::new();
        stream.read_to_string(&mut reply)?;
        let total_us = t0.elapsed().as_micros();

        println!(
            "Krok {:2} ({}): celkem IPC+Wayland = {:4} µs ({:.2} ms) | {}",
            i,
            cmd,
            total_us,
            total_us as f64 / 1000.0,
            reply.trim()
        );
        std::thread::sleep(Duration::from_millis(80));
    }

    println!("\nStav po testu:");
    send_command("status", true)?;
    Ok(())
}

fn main() {
    let arg = env::args().nth(1).unwrap_or_else(|| "help".to_string());

    let result = match arg.as_str() {
        "daemon" => run_daemon(),
        "next" => send_command("next", false),
        "prev" => send_command("prev", false),
        "ping" => send_command("ping", true),
        "status" => send_command("status", true),
        "bench" => run_bench(),
        _ => {
            eprintln!(
                "Pouziti:\n  cosmic-ws-switcher daemon\n  cosmic-ws-switcher next\n  cosmic-ws-switcher prev\n  cosmic-ws-switcher status\n  cosmic-ws-switcher bench"
            );
            return;
        }
    };

    if let Err(e) = result {
        eprintln!("cosmic-ws-switcher: {e}");
        std::process::exit(1);
    }
}

## 3. Nastavení klávesových zkratek (`Super + ←` a `Super + →`)

Zkratky můžeš nastavit buď v grafickém **Nastavení COSMIC -> Klávesnice -> Vlastní zkratky**, nebo přímo zapsáním do konfiguračního souboru COSMICu:

* **Předchozí okno (`Super + Left`):** `/home/<uzivatel>/.local/bin/cosmic-ws-switcher prev`
* **Další okno (`Super + Right`):** `/home/<uzivatel>/.local/bin/cosmic-ws-switcher next`

Pokud chceš zkratky nastavit automaticky přes terminál (pozor: přepíše případné jiné vlastní zkratky v souboru `custom`):
```bash
mkdir -p "$HOME/.config/cosmic/com.system76.CosmicSettings.Shortcuts/v1"
cat << EOF > "$HOME/.config/cosmic/com.system76.CosmicSettings.Shortcuts/v1/custom"
{
    (
        modifiers: [
            Super,
        ],
        key: "Left",
        description: Some("prev"),
    ): Spawn("$HOME/.local/bin/cosmic-ws-switcher prev"),
    (
        modifiers: [
            Super,
        ],
        key: "Right",
        description: Some("next"),
    ): Spawn("$HOME/.local/bin/cosmic-ws-switcher next"),
}
EOF
```
