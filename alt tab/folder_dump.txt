# Alt‑Tab: mapa zdrojů a verzí

Stav zmapovaný 14. 10. 2026 ze souborů v tomto repozitáři. Účelem této přípravy je porozumět kódu před opravami. Původní soubory verzí 1.0–1.3 nebyly změněny.

## Domluvený způsob práce

- Pracujeme na Macu a upravujeme soubory pro Linux.
- Instalaci a ověření v přihlášeném prostředí COSMIC provádí uživatel ručně na Linuxu.
- Na Macu nespouštět zdejší instalátory, služby ani přepínač. Při této přípravě se nic nekompilovalo ani neinstalovalo.
- Chyby budeme řešit až v navazujícím zadání. Tento přehled není potvrzením funkčnosti v COSMIC.
- Z obsahu repozitáře nevíme, která varianta je právě nainstalovaná na uživatelově Linuxu. Nejvyšší číslo složky samo o sobě neurčuje používanou verzi.

## Co je v Python payloadu

Rust není přeložený do Pythonu. Oba instalátory verze 1.1 obsahují proměnnou `PAYLOAD`:

```text
Python instalátor
  → PAYLOAD: Base64 text
  → dekódování na archiv .tar.gz
  → ověření PAYLOAD_SHA256
  → rozbalení Rustového projektu včetně Cargo.toml, Cargo.lock a config/
  → cargo test a cargo build na Linuxu
  → nativní binárka cosmic-ext-app-switcher
  → instalace binárky, uživatelské služby a autostartu
```

Archivy obsahují zdrojové soubory, nikoli předkompilovanou binárku. Závislosti nejsou přibalené jako kompletní offline kopie; Cargo je podle potřeby získává při sestavení.

Python obstarává rozbalení, sestavení, zálohy, instalaci a obnovu. Samotné přepínání oken, historie a vykreslování jsou v Rustu.

## Jak přepínač funguje

1. Rustový proces s `--daemon` drží spojení s Waylandem. Každému oknu přidělí vlastní číselný klíč. Události aktivace posouvají okna v historii MRU (naposledy použité první). Identitou není název okna ani aplikace.
2. Historie žije v paměti služby a začíná jejím spuštěním. Při nečinnosti služba čeká v `poll()` na Wayland nebo lokální požadavek; neprovádí časované vzorkování aktivního okna.
3. Zkratka spustí binárku bez argumentů, případně s `--reverse`. Pokud už UI existuje, další proces mu pošle `next` nebo `prev` a skončí.
4. Nové UI si vyžádá seřazený seznam oken od služby. Během výběru používá tento neměnný seznam. Dopředný první výběr je index 1, tedy předchozí okno, pokud jsou alespoň dvě.
5. UI zobrazuje lištu přes Wayland Layer Shell. Tab, Shift+Tab, šipky a myš mění výběr; uvolnění Alt/Super nebo Enter jej potvrzuje; Escape a ztráta focusu ruší výběr.
6. Potvrzení pošle službě dvojici `generation` a klíč okna. Služba odmítne zastaralý požadavek po svém restartu nebo okno, které už neexistuje. Historii aktualizují události aktivace od compositoru.

Jsou zde dva odlišné sockety v `XDG_RUNTIME_DIR`:

| Socket | Účel |
| --- | --- |
| `cosmic-ext-app-switcher.sock` | Krátké příkazy `next`/`prev` existujícímu UI. |
| `cosmic-ext-app-switcher-mru.sock` | JSON požadavky `List`, `Activate` a `Ping` pro službu historie. |

## Rozdíly důležité pro budoucí opravy

Mezi oběma payloady 1.1 se liší pouze `src/main.rs`, `src/app.rs` a `src/ui.rs`. Zbývajících 16 archivovaných souborů je shodných. Pythonová instalační logika je stejná; mimo payload a kontrolní součet se mění jen názvy skriptu v úvodních příkladech.

Varianta `fixed` předpočítává `visuals`, čeká 28 ms před zobrazením obsahu (`ready`), používá průhledné okno a pevné rozměry buněk i lišty. Při potvrzení/zrušení nastavuje `finishing`, skryje obsah a odstraňuje UI socket. Startovní zámek drží až do získání seznamu oken. Změny zaznamenáváme jako implementaci; jejich účinek na blikání zde nebyl ověřen.

Poznámky 1.2 obsahují obdobu této varianty s přeuspořádanými importy, formátováním a méně komentáři. Python instalátor začíná na řádku 1189 a sestavuje projekt ze složky; před sestavením ještě volá `cargo test`.

Verze 1.3 slučuje logiku do jednoho souboru. Oproti rozbalenému `fixed` chybějí testovací moduly, některé komentáře a diagnostické výpisy; zkrácená je i chyba při chybějících Wayland rozhraních. `install.py` 1.3 už před sestavením `cargo test` nevolá. Rozbalený přepínač 1.1 má 16 unit testů: historie 6, ikony 3, UI 3, kontrola protokolů 4. Applet má další 4 vlastní testy.

`WorkspaceScope::CurrentWorkspace` v posuzovaných MRU verzích vrací všechna okna. Původní `config/src/lib.rs` tuto možnost záměrně skrývá ve výběru. Filtr aktuálního monitoru se řídí výstupy naposledy použitého okna. To je existující omezení zdrojů, nikoli nově provedená změna.

## Instalátor a kontrola této přípravy

def require_linux():

@contextmanager
def idle_ui():
    runtime = os.environ.get('XDG_RUNTIME_DIR')
    if not runtime:
        raise RuntimeError('Chybi XDG_RUNTIME_DIR; spust v prihlasene relaci COSMIC.')
    with (Path(runtime) / 'cosmic-ext-app-switcher-ui.lock').open('a') as lock:

def status():
    return subprocess.run(['systemctl', '--user', 'is-active', '--quiet', SERVICE]).returncode == 0


def atomic_bytes(path, data, mode):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(prefix='.' + path.name + '.', dir=path.parent)
    try:
        with os.fdopen(fd, 'wb') as output:
            output.write(data)
            output.flush()
            os.fsync(output.fileno())
        os.chmod(tmp, mode)
        os.replace(tmp, path)
    finally:
        if os.path.lexists(tmp):
            os.unlink(tmp)


def backup(paths):
    folder = BASE / 'backups' / datetime.datetime.now().strftime('%Y%m%d-%H%M%S-%f')
    folder.mkdir(parents=True, mode=0o700)
    items = []
    for i, target in enumerate(paths):
        item = {'path': str(target), 'kind': 'missing'}
        if target.is_symlink():
            item.update(kind='symlink', link=os.readlink(target))
        elif target.is_file():
            name = str(i) + '.backup'
            shutil.copy2(target, folder / name)
            item.update(kind='file', file=name, mode=target.stat().st_mode & 0o777)
        elif target.exists():
            raise RuntimeError(f'Neocekavany typ cile: {target}')
        items.append(item)
    manifest = {'items': items, 'service_was_active': status()}
    (folder / 'manifest.json').write_text(json.dumps(manifest, indent=2), encoding='utf-8')
    return folder


def restore(folder):
    manifest = json.loads((folder / 'manifest.json').read_text(encoding='utf-8'))
    expected = {str(x) for x in [BIN, UNIT, START, AUTOSTART]}
    if {item['path'] for item in manifest['items']} != expected:
        raise RuntimeError('Zaloha neodpovida teto instalaci.')
    for item in manifest['items']:
        if item['kind'] == 'file' and not (folder / item['file']).is_file():
            raise RuntimeError('V zaloze chybi soubor; obnova nebyla zahajena.')
    subprocess.run(['systemctl', '--user', 'stop', SERVICE], check=False)
    for item in manifest['items']:
        target = Path(item['path'])
        if item['kind'] == 'file':
            atomic_bytes(target, (folder / item['file']).read_bytes(), item['mode'])
        elif item['kind'] == 'symlink':
            target.unlink(missing_ok=True)
            target.symlink_to(item['link'])
        else:
            target.unlink(missing_ok=True)
    run(['systemctl', '--user', 'daemon-reload'])
    if manifest['service_was_active']:
        run(['systemctl', '--user', 'start', SERVICE])
    print('Predchozi instalace byla obnovena.', flush=True)


def import_environment():

def desktop_quote(value):
    value = value.replace('%', '%%')
    for character in ['\\', '"', '`', '$']:
        value = value.replace(character, '\\' + character)
    value = value.replace('\\', '\\\\')
    return '"' + value + '"'

    run([cargo, 'build', '--locked', '--release', '--bin', 'cosmic-ext-app-switcher'], cwd=source_dir, env=env)

    run([new_binary, '--check-compat'])
    if check_only:
        print('Kontrola hotova. Testy, sestaveni a Wayland kontrola prosly. Instalace zustava beze zmen.')
        return

    with idle_ui():
        install_binary(new_binary)


def install_binary(new_binary):
    print('2/3 Vytvarim zalohu a instaluji prepinac.', flush=True)
    folder = backup([BIN, UNIT, START, AUTOSTART])
    try:
        subprocess.run(['systemctl', '--user', 'stop', SERVICE], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        atomic_bytes(BIN, new_binary.read_bytes(), 0o755)
        unit = '''[Unit]
Description=COSMIC Alt-Tab per-window MRU history
PartOf=graphical-session.target
After=graphical-session.target
StartLimitIntervalSec=60
StartLimitBurst=3

[Service]
Type=simple
ExecStart="%h/.local/bin/cosmic-ext-app-switcher" --daemon
Restart=on-failure
RestartSec=5
UMask=0077
'''
        atomic_bytes(UNIT, unit.encode(), 0o644)
        starter = '''#!/bin/sh
set -eu
[ -n "${WAYLAND_DISPLAY:-}" ] || exit 0
systemctl --user import-environment WAYLAND_DISPLAY
[ -z "${DISPLAY:-}" ] || systemctl --user import-environment DISPLAY
systemctl --user restart cosmic-ext-app-switcher-mru.service
'''
        atomic_bytes(START, starter.encode(), 0o755)
        desktop = '[Desktop Entry]\nType=Application\nName=COSMIC Alt-Tab MRU history\nExec=' + desktop_quote(str(START)) + '\nTerminal=false\nOnlyShowIn=COSMIC;\n'
        atomic_bytes(AUTOSTART, desktop.encode(), 0o644)
        run(['systemctl', '--user', 'daemon-reload'])
        import_environment()
        run(['systemctl', '--user', 'start', SERVICE])

        print('3/3 Kontroluji spojeni s MRU sluzbou.', flush=True)
        deadline = time.monotonic() + 15
        while True:
            result = subprocess.run([BIN, '--mru-check'], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
            if result.returncode == 0:
                break
            if time.monotonic() >= deadline:
                raise RuntimeError('Sluzba se nespustila; obnovuji puvodni instalaci.')
            time.sleep(0.2)
        atomic_bytes(BASE / 'last-backup', (str(folder) + '\n').encode(), 0o600)
    except BaseException:
        restore(folder)
        raise

    print('\nHOTOVO. Prepinac je nainstalovany a sluzba bezi.')


def main():
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    group = parser.add_mutually_exclusive_group()
    group.add_argument('--rollback', action='store_true', help='Obnovi predchozi zalohu')
    group.add_argument('--check-only', action='store_true', help='Testy a sestaveni bez vymeny instalace (pouze Linux/COSMIC)')
    args = parser.parse_args()

    require_linux()
    if args.check_only:
        install(PROJECT_DIR, check_only=True)
        return
    BASE.mkdir(parents=True, exist_ok=True)
    with (BASE / 'installer.lock').open('a') as lock:
        fcntl.flock(lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
        if args.rollback:
            marker = BASE / 'last-backup'
            if not marker.is_file():
                raise RuntimeError('Nebyla nalezena zaloha z uspesne instalace.')
            with idle_ui():
                restore(Path(marker.read_text().strip()))
                marker.unlink()
        else:
            install(PROJECT_DIR)


if __name__ == '__main__':
    try:
        main()
    except (Exception, KeyboardInterrupt) as error:

        raise SystemExit(1)

# COSMIC Alt‑Tab MRU 1.4.0

Nová pracovní verze z 14. 10. 2026. Obsahuje celý zdrojový projekt a instalátor pro ruční spuštění na Linuxu. Verze 1.0–1.3 a původní Python payloady jsou ponechané beze změny.

**Stav ověření:** na Macu prošlo 7 testů instalátoru se simulovaným sestavením a systémovými příkazy. Rustové sestavení, 27 testů přepínače a grafické chování v COSMIC zatím nejsou ověřené; zde není dostupný Cargo/Rust ani Linuxová relace. Tato verze není potvrzenou opravou zaznamenaných segfaultů nebo zamrzání compositoru.

## Co se změnilo

- `src/ipc.rs`: UI drží zámek až do návratu hlavní smyčky a úklidu. Další stisky zkratky se posílají přímo běžícímu UI, takže nepotřebují tento zámek získat. Druhá instance nemůže během zavírání vytvořit další povrch.
- Socket má jednoho vlastníka. Při odstranění kontroluje zařízení a inode; starý úklid nesmaže nahrazený socket. Z `Activate`, `Cancel` a konce `main()` zmizelo opakované mazání pathname.
- Předaný `next`/`prev` dostává odpověď. Zavírací UI odpovídá „zkus znovu“; nové spuštění čeká omezenou dobu na konec vlastníka. Nejasné doručení při chybě spojení se hlásí jako chyba, nikoli jako úspěch či důvod ke smazání cizího socketu. Při takové chybě se stisk automaticky nepřehrává, aby se výběr neposunul dvakrát.
- `src/app.rs`: odstranění layer surface a konec procesu se neposílají současně. Po `destroy_layer_surface` aplikace čeká na `LayerEvent::Done`; případnou aktivaci vybraného okna pak provede mimo UI vlákno a teprve po odpovědi ukončí proces. Pokud do 2 sekund nepřijde potvrzení odstranění, zapíše chybu a ukončí se bez aktivace.
- `src/lifecycle.rs`: obsah lišty zůstává skrytý, dokud neuplyne 35 ms **a** nepřijde první `Window::Opened` z konfigurace layer surface. Pozdní časovač během zavírání panel znovu neodkryje. Tři sekundy bez konfigurace vyvolají zavření místo čekání bez konce.
- `src/icons.rs`: `.desktop` soubory, cesty i bajty ikon se načítají před vytvořením povrchu. `view()` klonuje připravené `icon::Handle`; nevyhledává názvy ikon ani nečte `.desktop` soubory. Dekódování a nahrání textur dál zajišťuje renderer.
- `src/ui.rs`: zachované pevné rozměry kořene, lišty a ikon; `ContentFit::Contain` zachovává poměr stran ikony.
- Trvalá chyba UI listeneru ukončí UI místo těsné smyčky opakovaných `accept()`. MRU služba rozpozná ukončený/chybný descriptor z `poll()`.
- `CurrentWorkspace` vrací výslovnou chybu, protože původní protokol neposkytuje spolehlivou filtraci této volby. Už tiše nevrací všechna okna. Běžně nabízené režimy „All workspaces“ a „Current monitor“ zůstávají.
- Služba má `RestartSec=5`, `StartLimitIntervalSec=60` a `StartLimitBurst=3`, aby se při opakovaném pádu stále dokola nespouštěla.
- Release build uchovává symboly a základní ladicí informace pro rozbor případného dalšího pádu.

MRU algoritmus v `src/mru.rs` včetně původních testů je bajtově shodný s výchozím payloadem `fixed`. Šipky, Tab, Shift+Tab, Enter, Escape a potvrzení uvolněním Alt/Super jsou zachované. Snímek pořadí oken se během výběru nepřeskupuje.

## Ruční kontrola a instalace na Linuxu

Přenes **celou složku `ver 1.4`**, včetně `src/`, `config/`, `applet/`, `Cargo.toml` a `Cargo.lock`. `install.py` zde nemá vložený payload a samostatně nestačí. Vyžaduje Rust/Cargo podporující edition 2024, `pkg-config`, vývojové knihovny Wayland/xkbcommon a uživatelský systemd. Nastavená zkratka má už ukazovat na `~/.local/bin/cosmic-ext-app-switcher`.

V terminálu otevřeném v této složce, uvnitř přihlášeného COSMIC a **bez sudo**, můžeš nejprve spustit:

```sh
python3 install.py --check-only
```

Provede Rustové testy, release sestavení, kontrolu verze výsledné binárky a kontrolu dostupných Wayland rozhraní. Může stáhnout chybějící připnuté závislosti a zapisuje build cache; nemění instalovanou binárku, službu ani autostart.

Samotná instalace:

```sh
python3 install.py
```

Instalátor také nejprve provede všechny uvedené kontroly. Před výměnou vyžaduje zavřený přepínač, uloží zálohu a vymění pouze vlastní binárku, službu a autostart. Při chybě po vytvoření zálohy se pokusí obnovit předchozí stav. Během výměny nepoužívej Alt‑Tab ani staré instalátory. Starší skripty z historických složek stále mohou přepsat novější instalaci, pokud je ručně spustíš.

Obnova poslední uložené instalace:

```sh
python3 install.py --rollback
```

Tato verze na macOS odmítne instalaci i rollback ještě před vytvářením instalačních adresářů. Nemění `swaync`, `nvidia-settings`, ovladače ani systémové knihovny. Kompilace používá výchozí limit dvou úloh; nastavené `CARGO_BUILD_JOBS` respektuje.

## Co ověřit v COSMIC

1. Po instalaci ověř `~/.local/bin/cosmic-ext-app-switcher --version` — očekává se `1.4.0` — a `--mru-check`.
2. Myší aktivuj tři různá okna. Opakovaný krátký Alt‑Tab má střídat dvě poslední. Vyzkoušej také dvě okna stejné aplikace.
3. Podrž Alt, procházej Tabem, Shift+Tabem a šipkami. Escape má zrušit výběr; Enter nebo uvolnění Alt jej potvrdit.
4. Několikrát rychle zopakuj celé stisknutí a uvolnění Alt‑Tab. Sleduj blikání, ztracené stisky, visící overlay a souběžné UI procesy.
5. Zavři vybrané okno během přepínání; program nemá aktivovat jiné okno pod stejnou identitou.
6. Ověř obvyklé měřítko obrazovky a monitory, které používáš. Zvlášť zaznamenej, zda se problém objevuje jen na určitém výstupu.
7. Po odhlášení/přihlášení zkontroluj start MRU služby. Historie se po restartu služby sbírá znovu.

Pokud dojde k pádu, užitečné jsou tyto čtecí příkazy na Linuxu:

```sh
~/.local/bin/cosmic-ext-app-switcher --version
systemctl --user status cosmic-ext-app-switcher-mru.service --no-pager
journalctl --user -u cosmic-ext-app-switcher-mru.service -n 100 --no-pager
coredumpctl list --since "15 minutes ago" --no-pager
```

Pro PID odpovídající novému pádu následně `coredumpctl info PID --no-pager`, případně `coredumpctl debug PID` a v GDB `thread apply all bt`. `PID` nahraď číslem z aktuálního seznamu. `RUST_BACKTRACE=1` zachycuje Rustové paniky; samo o sobě nevysvětlí SIGSEGV v nativní knihovně. Dostupnost core dumpů a GDB závisí na Linuxovém systému.

## Diagnostika: co je doložené a co zatím ne

Závod při několikanásobném odstranění socketu byl doložený kódem a je zde odstraněný. Ukončování pomocí `Task::batch([destroy, exit])` neposkytovalo požadované pořadí; nyní se čeká na událost z toolkitové implementace.

Samotné `UnixStream::connect()` nemusí selhat jen proto, že aplikace přestala volat `accept()`; spojení může ještě přijmout kernelový backlog. Proto nová varianta používá potvrzení příkazu, nikoli jen úspěšný `connect()` jako důkaz funkčního UI.

Pevná prodleva 35 ms není potvrzení konfigurace, GPU fence ani záruka správného stride. Neshoda velikosti layoutu sama o sobě nedokazuje poškození řádkování textury. Časová prodleva zde slouží jen ke skrytí krátkého vyvolání a je doplněná událostí konfigurace. Ani načtení ikon do paměti nepotvrzuje dokončené vykreslení GPU.

Záznamy SIGSEGV v `libwayland-client` vyžadují úplnou cestu k binárce a zásobník konkrétního pádu. Chyby `swaync.service` nebo `nvidia-settings-autostart` samy nepotvrzují reset NVIDIA ani příčinu zamrznutí. Hlášení compositoru o importu textury je další samostatný podklad k prověření. Tato úprava proto neslibuje odstranění všech systémových dropů.

Zkontrolované související reporty compositoru: [#2768, import mezi GPU](https://github.com/pop-os/cosmic-comp/issues/2768) a [#2655, import/renderování na jedné NVIDIA](https://github.com/pop-os/cosmic-comp/issues/2655). Podobné hlášení v reportu neprokazuje stejnou příčinu na tomto počítači.

## Původ, implementační podklady a testy

Základ: čitelný payload `rozbalene-zdroje/ver-1.1-fixed`, jehož logika odpovídá sloučené variantě 1.3. Obnovuje také její chybějící Cargo workspace a původní testy. Python instalátor vychází z 1.3. Verze všech tří místních Cargo balíčků je `1.4.0`; verze externích závislostí v `Cargo.lock` se nezměnily.

Ověřený zdroj závislostí, podle kterého je napsané čekání na události:

- libcosmic `417923fbafc0f38a63846b307036e4f20fc4960d`; [ikony a handles](https://github.com/pop-os/libcosmic/blob/417923fbafc0f38a63846b307036e4f20fc4960d/src/widget/icon/handle.rs).
- Jeho Iced podmodul `7afd9ee0f83cfd1a4e9f9b56cf0f365e5ae60347`; [převod Configure na Opened a zpracování Done](https://github.com/pop-os/iced/blob/7afd9ee0f83cfd1a4e9f9b56cf0f365e5ae60347/winit/src/platform_specific/wayland/sctk_event.rs).
- [Destroy a navazující Done](https://github.com/pop-os/iced/blob/7afd9ee0f83cfd1a4e9f9b56cf0f365e5ae60347/winit/src/platform_specific/wayland/event_loop/state.rs), [implementace Task::chain a Task::batch](https://github.com/pop-os/iced/blob/7afd9ee0f83cfd1a4e9f9b56cf0f365e5ae60347/runtime/src/task.rs). Samotné `chain()` řadí streamy úloh; nenahrazuje potvrzení dokončeného odstranění povrchu.

Lokální kontrola instalátoru (bez Cargo, systemd a skutečné instalace):

```sh
python3 -B -m unittest discover -s tests -v
```

Sedm testů bylo úspěšně spuštěno na Macu. Test živého socketu potřeboval povolit lokální Unix socket mimo omezení sandboxu. Testy sestavení a instalace používají simulované příkazy; jejich úspěch neznamená, že Rust byl zkompilovaný.

V `src/` je připraveno 27 Rustových testů: 16 původních, 5 pro IPC/vlastnictví socketu, 5 pro pořadí konfigurace a zavírání, 1 pro odmítnutí nepodporovaného rozsahu. Spouštějí se při Linuxové instalaci. Historický applet obsahuje ještě 4 vlastní testy; běžný instalátor applet nesestavuje ani neinstaluje.

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Serialize, Deserialize)]

    }
}

#[derive(Debug, Clone)]
pub struct Shortcut {
    reverse: bool,
    reply: Arc<Mutex<Option<tokio::sync::oneshot::Sender<bool>>>>,
}

impl Shortcut {
    fn acknowledge(&self, accepted: bool) -> bool {
        self.reply.lock().ok().and_then(|mut reply| reply.take())
            .is_some_and(|reply| reply.send(accepted).is_ok())
    }
}

pub struct AppSwitcher {

    pub toplevels: Vec<ToplevelEntry>,

    pub lifecycle: Lifecycle,

}

#[derive(Debug, Clone)]
pub enum Message {

    SelectPrev,

impl Application for AppSwitcher {
    type Executor = cosmic::executor::Default;
    type Flags    = (Vec<ToplevelEntry>, bool, String, Theme, UiListener);
    type Message  = Message;

    const APP_ID: &'static str = "io.github.cosmic-ext-app-switcher";

    fn core(&self) -> &Core { &self.core }
    fn core_mut(&mut self) -> &mut Core { &mut self.core }

    fn init(core: Core, flags: Self::Flags) -> (Self, Task<Message>) {
        let (toplevels, reverse, generation, theme_preset, listener) = flags;
        let n = toplevels.len();
        let selected = if reverse {
            n.saturating_sub(1)
        } else {
            1.min(n.saturating_sub(1))
        };

        let theme = theme_preset.values();
        let visuals: Vec<PreparedVisual> = toplevels
            .iter()
            .map(|entry| prepare_visual_for(&entry.app_id, &entry.title, theme.icon_size))
            .collect();

        let (surface_w, surface_h) = crate::ui::surface_size(toplevels.len(), &theme);

        let surface_id = WindowId::unique();
        let layer_task = get_layer_surface::<cosmic::Action<Message>>(SctkLayerSurfaceSettings {
            id: surface_id,
            layer: Layer::Overlay,
            keyboard_interactivity: KeyboardInteractivity::Exclusive,
            anchor: Anchor::empty(),
            size: Some((Some(surface_w), Some(surface_h))),
            ..Default::default()
        });

        let ready_task = Task::perform(
            async { tokio::time::sleep(REVEAL_DELAY).await; },
            |_| cosmic::Action::App(Message::GraceElapsed),
        );
        let startup_timeout = Task::perform(
            async { tokio::time::sleep(Duration::from_secs(3)).await; },
            |_| cosmic::Action::App(Message::StartupTimeout),
        );

        (
            AppSwitcher {
                core,
                toplevels,
                visuals,
                selected,
                generation,
                lifecycle: Lifecycle::default(),
                listener,
                surface_id,
                theme,
            },
            Task::batch([layer_task, ready_task, startup_timeout]),
        )
    }

    fn update(&mut self, msg: Message) -> Task<Message> {
        // These replies must still be processed during teardown. In particular,
        // never acknowledge a shortcut that this UI can no longer apply.
        match &msg {
            Message::Shortcut(shortcut) => {
                if shortcut.acknowledge(!self.lifecycle.is_closing()) && !self.lifecycle.is_closing() {
                    return self.update(if shortcut.reverse { Message::SelectPrev } else { Message::SelectNext });
                }
                return Task::none();
            }
            Message::SurfaceClosed(id) if *id == self.surface_id => {
                let key = match self.lifecycle.surface_closed() {
                    AfterClose::Ignore => return Task::none(),
                    AfterClose::Exit => return iced::exit(),
                    AfterClose::Activate(key) => key,
                };
                let generation = self.generation.clone();
                // The toolkit has removed the surface. The potentially slow
                // daemon request runs off the UI thread and completes before exit.
                return Task::perform(
                    async move {
                        tokio::task::spawn_blocking(move || crate::wayland::activate(&generation, key)
                            .map_err(|error| format!("{error:#}")))
                            .await.map_err(|error| error.to_string()).and_then(|result| result)
                    },
                    |result| cosmic::Action::App(Message::ActivationFinished(result)),
                );
            }
            Message::ActivationFinished(result) => {
                if let Err(error) = result { log::error!("Could not activate selected window: {error}"); }
                return iced::exit();
            }
            Message::ShutdownTimeout if self.lifecycle.close_timed_out() => {
                log::error!("Timed out waiting for layer-surface teardown; exiting without activation");
                return iced::exit();
            }
            _ => {}
        }
        if self.lifecycle.is_closing() { return Task::none(); }
        let n = self.toplevels.len();
        if n == 0 { return iced::exit(); }
        match msg {
            Message::GraceElapsed => {
                self.lifecycle.grace_elapsed();
            }
            Message::SurfaceOpened(id) if id == self.surface_id => {
                // In the pinned Iced version, Opened is emitted on the first
                // layer-shell Configure, after its logical size is updated.
                self.lifecycle.configured();
            }
            Message::StartupTimeout if !self.lifecycle.is_configured() => {
                log::error!("Layer surface did not configure in time");
                return self.finish(None);
            }
            Message::IpcFailed(error) => {
                log::error!("UI socket listener failed: {error}");
                return self.finish(None);
            }
            Message::SelectNext => {
                self.selected = (self.selected + 1) % n;
            }
            Message::SelectPrev => {
                self.selected = (self.selected + n - 1) % n;
            }
            Message::SelectIndex(i) => {
                if i < n { self.selected = i; }
            }
            Message::Activate => {
                return self.finish(Some(self.toplevels[self.selected].handle_key));
            }
            Message::Cancel => {
                return self.finish(None);
            }
            Message::KeyEvent(ke) => match ke {
                keyboard::Event::KeyPressed { key, modifiers, .. } => match key {
                    iced::keyboard::Key::Named(Named::Tab) => {
                        return self.update(if modifiers.shift() {
                            Message::SelectPrev
                        } else {
                            Message::SelectNext
                        });
                    }
                    iced::keyboard::Key::Named(Named::ArrowRight) | iced::keyboard::Key::Named(Named::ArrowDown) => {
                        return self.update(Message::SelectNext);
                    }
                    iced::keyboard::Key::Named(Named::ArrowLeft) | iced::keyboard::Key::Named(Named::ArrowUp) => {
                        return self.update(Message::SelectPrev);
                    }
                    iced::keyboard::Key::Named(Named::Escape) => {
                        return self.update(Message::Cancel);
                    }
                    iced::keyboard::Key::Named(Named::Enter) => {
                        return self.update(Message::Activate);
                    }
                    _ => {}
                },
                keyboard::Event::KeyReleased { key, .. } => match key {
                    iced::keyboard::Key::Named(Named::Alt)
                    | iced::keyboard::Key::Named(Named::AltGraph)
                    | iced::keyboard::Key::Named(Named::Super) => {
                        return self.update(Message::Activate);
                    }
                    _ => {}
                },
                keyboard::Event::ModifiersChanged(mods) => {
                    if !mods.alt() && !mods.logo() {
                        return self.update(Message::Activate);
                    }
                }
            },
            _ => {},
        }
        Task::none()
    }

    fn subscription(&self) -> Subscription<Message> {
        let key_sub = event::listen_with(|event, _status, window| {
            match event {
                Event::Keyboard(ke) => Some(Message::KeyEvent(ke)),
                Event::Window(iced::window::Event::Unfocused) => Some(Message::Cancel),
                Event::Window(iced::window::Event::Opened { .. }) => Some(Message::SurfaceOpened(window)),
                Event::PlatformSpecific(iced::event::PlatformSpecific::Wayland(
                    iced::event::wayland::Event::Layer(iced::event::wayland::LayerEvent::Done, _, id)
                )) => Some(Message::SurfaceClosed(id)),
                _ => None,
            }
        });

        let socket_sub = {
            use cosmic::iced::futures::SinkExt;
            Subscription::run_with(self.listener.clone(), |source| {
                let source = source.clone();
                cosmic::iced::stream::channel(16, move |mut tx: cosmic::iced::futures::channel::mpsc::Sender<Message>| async move {
                    use tokio::io::{AsyncReadExt, AsyncWriteExt};
                    let listener = match source.try_clone().and_then(tokio::net::UnixListener::from_std) {
                        Ok(listener) => listener,
                        Err(error) => {
                            let _ = tx.send(Message::IpcFailed(error.to_string())).await;
                            std::future::pending::<()>().await;
                            unreachable!();
                        }
                    };
                    loop {
                        let (mut stream, _) = match listener.accept().await {
                            Ok(client) => client,
                            Err(error) if error.kind() == std::io::ErrorKind::Interrupted => continue,
                            Err(error) => {
                                let _ = tx.send(Message::IpcFailed(error.to_string())).await;
                                break;
                            }
                        };
                        let mut buf = Vec::new();
                        let read = tokio::time::timeout(Duration::from_millis(500),
                            (&mut stream).take(16).read_to_end(&mut buf)).await;
                        if !matches!(read, Ok(Ok(_))) { continue; }
                        let reverse = match buf.as_slice() { b"next" => false, b"prev" => true, _ => continue };
                        let (reply, response) = tokio::sync::oneshot::channel();
                        let shortcut = Shortcut { reverse, reply: Arc::new(Mutex::new(Some(reply))) };
                        if tx.send(Message::Shortcut(shortcut)).await.is_err() { break; }
                        if let Ok(Ok(accepted)) = tokio::time::timeout(Duration::from_secs(1), response).await {
                            let _ = tokio::time::timeout(Duration::from_millis(500),
                                stream.write_all(if accepted { b"1" } else { b"0" })).await;
                        }
                    }
                    // A permanent accept error must not turn into a tight retry loop.
                    std::future::pending::<()>().await;
                })
            })
        };

        Subscription::batch([key_sub, socket_sub])
    }

    fn view(&self) -> Element<'_, Message> {
        crate::ui::view(self)
    }

    fn view_window(&self, _id: WindowId) -> Element<'_, Message> {
        crate::ui::view(self)
    }
}

impl AppSwitcher {
    fn finish(&mut self, key: Option<u64>) -> Task<Message> {
        if !self.lifecycle.begin_close(key) { return Task::none(); }
        // Do not batch Destroy with Exit: wait for the toolkit's LayerEvent::Done.
        // This timer bounds a failed teardown; it is not a frame synchronization.
        Task::batch([
            destroy_layer_surface(self.surface_id),
            Task::perform(
                async { tokio::time::sleep(Duration::from_secs(2)).await; },
                |_| cosmic::Action::App(Message::ShutdownTimeout),
            ),
        ])
    }
}

pub fn run(
    toplevels: Vec<ToplevelEntry>,
    reverse: bool,
    generation: String,
    theme: Theme,
    listener: UiListener,
) -> Result<()> {
    let settings = Settings::default()
        .no_main_window(true)
        .exit_on_close(false)
        .transparent(true);
    cosmic::app::run::<AppSwitcher>(settings, (toplevels, reverse, generation, theme, listener))
        .map_err(|e| anyhow::anyhow!("{e:?}"))
}

use cosmic::widget::icon;
use freedesktop_desktop_entry::{DesktopEntry, Iter as DesktopIter};
use std::collections::HashSet;
use std::path::{Path, PathBuf};

/// Rendered when an app's icon can't be resolved. libcosmic substitutes an *empty* SVG for
/// a name that isn't in the theme, so without this a window in the strip renders as a blank
/// cell and reads as a window that's missing entirely (#9).
const FALLBACK_ICON: &str = "application-x-executable";

/// What to draw for one window.
pub enum AppIcon {
    /// A name to look up in the icon theme. Always one that resolved.
    Named(String),
    /// An icon file named outright by a `.desktop` entry, as Snap and some AppImage
    /// entries do. Those paths are outside any theme, so a name lookup can't find them.
    File(PathBuf),
}

/// How one window is presented in the strip.
pub struct AppVisual {
    pub icon: AppIcon,
    /// What to print under the strip when this window is selected.
    pub label: String,
}

/// Ready-to-render data: no theme lookup or .desktop access in ui::view().
pub struct PreparedVisual {
    pub handle: icon::Handle,
    pub label: String,
}

pub fn prepare_visual_for(app_id: &str, window_title: &str, size: u16) -> PreparedVisual {
    let visual = visual_for(app_id, window_title, size);
    let path = match visual.icon {
        AppIcon::Named(name) => icon::from_name(name).size(size).path(),
        AppIcon::File(path) => Some(path),
    };
    // Own the bytes before requesting a Wayland surface. Decoding/uploading is
    // still the renderer's job; a cached handle is not a GPU fence.
    let handle = path.as_ref().and_then(|path| {
        let bytes = std::fs::read(path).ok()?;
        let mut handle = if path.extension().is_some_and(|ext| ext == "svg") {
            icon::from_svg_bytes(bytes)
        } else {
            icon::from_raster_bytes(bytes)
        };
        handle.symbolic = path.file_stem().and_then(|stem| stem.to_str())
            .is_some_and(|stem| stem.ends_with("-symbolic"));
        Some(handle)
    }).unwrap_or_else(|| icon::from_svg_bytes(
        br##"<svg xmlns="http://www.w3.org/2000/svg" width="64" height="64" viewBox="0 0 64 64"><rect x="6" y="8" width="52" height="48" rx="7" fill="#74849b"/><path d="M6 22h52" stroke="#dce5ef" stroke-width="4"/></svg>"##.as_slice()
    ));
    PreparedVisual { handle, label: visual.label }
}

/// Resolves what to draw for `app_id`, at the size the icon will be drawn at: a name can
/// resolve at one size and not another, so the check has to use the size we'll render.
pub fn visual_for(app_id: &str, window_title: &str, size: u16) -> AppVisual {
    // Steam games: the per-game icon isn't reliably resolvable, so use Steam's own. The
    // window title is the game's name, which beats every other label we could pick.
    if app_id.starts_with("steam_app_") {
        return AppVisual {
            icon: resolve("steam", size),
            label: first_non_empty(&[window_title, "Steam"]).to_string(),
        };
    }

    let entry = desktop_entry_for(app_id);
    let label = entry.as_ref()
        .and_then(|e| e.name.as_deref())
        .filter(|n| !n.is_empty())
        .unwrap_or_else(|| first_non_empty(&[window_title, app_id, "Unknown"]))
        .to_string();

    let icon = match entry.and_then(|e| e.icon) {
        // An absolute Icon= that exists is the icon, no theme lookup involved.
        Some(field) if Path::new(&field).is_absolute() && Path::new(&field).is_file() => {
            AppIcon::File(PathBuf::from(field))
        }
        // An absolute Icon= that doesn't exist still names the icon by its stem, which is
        // how Steam's entries point at icons it installed into the theme.
        Some(field) => resolve(&icon_name_from_field(&field), size),
        // No entry found: reverse-DNS app_ids often end in their own icon name.
        None => resolve(app_id.split('.').next_back().unwrap_or(app_id), size),
    };

    AppVisual { icon, label }
}

fn first_non_empty<'a>(candidates: &[&'a str]) -> &'a str {
    candidates.iter().copied().find(|c| !c.is_empty()).unwrap_or_default()
}

/// Falls back to the generic icon if `name` isn't in the theme.
fn resolve(name: &str, size: u16) -> AppIcon {
    if icon::from_name(name).size(size).path().is_some() {
        return AppIcon::Named(name.to_string());
    }
    log::debug!("icon {name:?} not found at size {size}, falling back to {FALLBACK_ICON}");
    AppIcon::Named(FALLBACK_ICON.to_string())
}

/// The fields we use from a `.desktop` entry.
struct DesktopInfo {
    icon: Option<String>,
    name: Option<String>,
}

/// The `.desktop` entry describing `app_id`, if one can be found.
fn desktop_entry_for(app_id: &str) -> Option<DesktopInfo> {
    if app_id.is_empty() {
        return None;
    }
    let dirs = search_dirs();

    // Direct filename match: "firefox" -> "firefox.desktop"
    for dir in &dirs {
        if let Some(info) = read_entry(&dir.join(format!("{app_id}.desktop"))) {
            return Some(info);
        }
    }

    // Otherwise scan every entry for one that claims this app_id.
    for path in DesktopIter::new(dirs.clone()) {
        let Ok(bytes) = std::fs::read(&path) else { continue };
        let Ok(s) = std::str::from_utf8(&bytes) else { continue };
        let Ok(entry) = DesktopEntry::decode(&path, s) else { continue };
        let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or_default();
        let claims = entry.startup_wm_class().is_some_and(|c| c.eq_ignore_ascii_case(app_id))
            || stem_matches(stem, app_id);
        if claims {
            return Some(DesktopInfo {
                icon: entry.icon().map(ToString::to_string),
                name: entry.name(None).map(|n| n.to_string()),
            });
        }
    }

    log::debug!("no .desktop entry found for app_id {app_id:?}");
    None
}

/// Whether a `.desktop` filename describes `app_id`. Compositors report app_ids with
/// inconsistent case, and often report only the last component of a reverse-DNS name
/// (app_id "jdownloader" for "org.jdownloader.JDownloader.desktop").
fn stem_matches(stem: &str, app_id: &str) -> bool {
    stem.eq_ignore_ascii_case(app_id)
        || stem.rsplit('.').next().is_some_and(|last| last.eq_ignore_ascii_case(app_id))
}

fn read_entry(path: &Path) -> Option<DesktopInfo> {
    let bytes = std::fs::read(path).ok()?;
    let s = std::str::from_utf8(&bytes).ok()?;
    let entry = DesktopEntry::decode(path, s).ok()?;
    Some(DesktopInfo {
        icon: entry.icon().map(ToString::to_string),
        name: entry.name(None).map(|n| n.to_string()),
    })
}

/// Every directory that can hold `.desktop` files, in XDG precedence order.
fn search_dirs() -> Vec<PathBuf> {
    let home = std::env::var("HOME").unwrap_or_default();
    let data_home = std::env::var("XDG_DATA_HOME")
        .ok()
        .filter(|d| !d.is_empty())
        .unwrap_or_else(|| format!("{home}/.local/share"));
    let data_dirs = std::env::var("XDG_DATA_DIRS")
        .ok()
        .filter(|d| !d.is_empty())
        .unwrap_or_else(|| "/usr/local/share:/usr/share".to_string());

    let xdg = std::iter::once(data_home.clone())
        .chain(data_dirs.split(':').map(ToString::to_string))
        .filter(|d| !d.is_empty())
        .map(|d| PathBuf::from(d).join("applications"));

    // Flatpak's export dirs are in XDG_DATA_DIRS only for sessions that started after the
    // first install, and Snap's is never there, so name all three outright.
    let extra = [
        PathBuf::from("/var/lib/flatpak/exports/share/applications"),
        PathBuf::from(format!("{data_home}/flatpak/exports/share/applications")),
        PathBuf::from("/var/lib/snapd/desktop/applications"),
    ];

    let mut seen = HashSet::new();
    xdg.chain(extra).filter(|d| seen.insert(d.clone())).collect()
}

// If the Icon= field in a .desktop file is an absolute path, extract the stem
// (e.g. "/path/to/steam_icon_480.png" -> "steam_icon_480") so that from_name()
// can resolve it through the XDG icon theme where Steam has already installed it.
fn icon_name_from_field(icon: &str) -> String {
    if icon.starts_with('/') {
        Path::new(icon)
            .file_stem()
            .and_then(|s| s.to_str())
            .unwrap_or(icon)
            .to_string()
    } else {
        icon.to_string()
    }
}

//! One UI owner for the whole lifetime of its event loop, including teardown.
//! Other shortcut processes forward commands without taking the owner's lock.
use std::{
    fs::{File, OpenOptions},
    hash::{Hash, Hasher},
    io::{self, Read, Write},
    os::{fd::AsRawFd, unix::{fs::{FileTypeExt, MetadataExt, OpenOptionsExt, PermissionsExt}, net::{UnixListener, UnixStream}}},
    path::{Path, PathBuf},
    sync::Arc,
    time::{Duration, Instant},
};

const START_TIMEOUT: Duration = Duration::from_secs(5);
const REPLY_TIMEOUT: Duration = Duration::from_secs(2);

#[derive(Clone, Debug)]
pub struct UiListener(Arc<UnixListener>);

impl Hash for UiListener {
    fn hash<H: Hasher>(&self, state: &mut H) {
        self.0.as_raw_fd().hash(state);
    }
}

impl UiListener {
    pub fn try_clone(&self) -> io::Result<UnixListener> {
        self.0.try_clone()
    }
}

/// Removes only the socket inode we created, never a replacement at this path.
pub struct OwnedSocket {
    path: PathBuf,
    device: u64,
    inode: u64,
}

impl OwnedSocket {
    pub fn new(path: PathBuf) -> io::Result<Self> {
        let metadata = std::fs::symlink_metadata(&path)?;
        if !metadata.file_type().is_socket() {
            return Err(io::Error::other("Expected a Unix socket"));
        }
        Ok(Self { path, device: metadata.dev(), inode: metadata.ino() })
    }
}

impl Drop for OwnedSocket {
    fn drop(&mut self) {
        if let Ok(metadata) = std::fs::symlink_metadata(&self.path) {
            if metadata.file_type().is_socket()
                && metadata.dev() == self.device && metadata.ino() == self.inode
            {
                let _ = std::fs::remove_file(&self.path);
            }
        }
    }
}

pub struct UiOwner {
    // Fields drop in this order: listener, socket pathname, then lifetime lock.
    listener: UiListener,
    _socket: OwnedSocket,
    _lock: File,
}

impl UiOwner {
    pub fn listener(&self) -> UiListener {
        self.listener.clone()
    }

    fn try_claim(lock_path: &Path, socket_path: &Path) -> io::Result<Option<Self>> {
        let lock = OpenOptions::new().create(true).truncate(false)
            .read(true).write(true).mode(0o600).open(lock_path)?;
        if unsafe { libc::flock(lock.as_raw_fd(), libc::LOCK_EX | libc::LOCK_NB) } != 0 {
            let error = io::Error::last_os_error();
            return if error.kind() == io::ErrorKind::WouldBlock { Ok(None) } else { Err(error) };
        }
        // Only the lifetime-lock owner may remove a stale socket and bind a new one.
        match std::fs::symlink_metadata(socket_path) {
            Ok(metadata) if metadata.file_type().is_socket() => std::fs::remove_file(socket_path)?,
            Ok(_) => return Err(io::Error::other("UI socket path is occupied by a non-socket")),
            Err(error) if error.kind() == io::ErrorKind::NotFound => {},
            Err(error) => return Err(error),
        }
        let listener = UnixListener::bind(socket_path)?;
        let socket = OwnedSocket::new(socket_path.to_owned())?;
        std::fs::set_permissions(socket_path, std::fs::Permissions::from_mode(0o600))?;
        listener.set_nonblocking(true)?;
        Ok(Some(Self { listener: UiListener(Arc::new(listener)), _socket: socket, _lock: lock }))
    }
}

/// None means a live UI acknowledged and applied the shortcut.
pub fn claim_or_forward(runtime: &Path, reverse: bool) -> io::Result<Option<UiOwner>> {
    let lock = runtime.join("cosmic-ext-app-switcher-ui.lock");
    let socket = runtime.join("cosmic-ext-app-switcher.sock");
    let deadline = Instant::now() + START_TIMEOUT;
    loop {
        if let Some(owner) = UiOwner::try_claim(&lock, &socket)? {
            return Ok(Some(owner));
        }
        let remaining = deadline.saturating_duration_since(Instant::now());
        if remaining.is_zero() {
            return Err(io::Error::new(io::ErrorKind::TimedOut, "Previous switcher is still starting or closing"));
        }
        match forward(&socket, reverse, remaining.min(REPLY_TIMEOUT))? {
            Forward::Accepted => return Ok(None),
            Forward::Retry => std::thread::sleep(Duration::from_millis(10).min(remaining)),
        }
    }
}

#[derive(Debug, PartialEq)]
enum Forward { Accepted, Retry }

fn forward(path: &Path, reverse: bool, timeout: Duration) -> io::Result<Forward> {
    let mut stream = match UnixStream::connect(path) {
        Ok(stream) => stream,
        Err(error) if matches!(error.kind(), io::ErrorKind::NotFound | io::ErrorKind::ConnectionRefused) => return Ok(Forward::Retry),
        Err(error) => return Err(error),
    };
    stream.set_read_timeout(Some(timeout))?;
    stream.set_write_timeout(Some(timeout))?;
    stream.write_all(if reverse { b"prev" } else { b"next" })?;
    stream.shutdown(std::net::Shutdown::Write)?;
    let mut reply = [0];
    // An ambiguous delivery is an error, not permission to replay the command or
    // delete another process's socket. Only an explicit busy reply is retried.
    stream.read_exact(&mut reply)?;
    match reply[0] {
        b'1' => Ok(Forward::Accepted),
        b'0' => Ok(Forward::Retry),
        _ => Err(io::Error::new(io::ErrorKind::InvalidData, "Invalid UI acknowledgement")),
    }
}

//! Ordering rules independent of the GUI, so shutdown races can be tested.
#[derive(Default)]
pub struct Lifecycle {
    configured: bool,
    grace_elapsed: bool,
    closing: bool,
    closed: bool,
    activation: Option<u64>,
}

#[derive(Debug, PartialEq)]
pub enum AfterClose { Ignore, Exit, Activate(u64) }

impl Lifecycle {
    pub fn configured(&mut self) { self.configured = true; }
    pub fn grace_elapsed(&mut self) { self.grace_elapsed = true; }
    pub fn is_configured(&self) -> bool { self.configured }
    pub fn is_closing(&self) -> bool { self.closing }
    pub fn visible(&self) -> bool { self.configured && self.grace_elapsed && !self.closing }

    pub fn begin_close(&mut self, activation: Option<u64>) -> bool {
        if self.closing { return false; }
        self.closing = true;
        self.activation = activation;
        true
    }

    pub fn surface_closed(&mut self) -> AfterClose {
        if self.closed { return AfterClose::Ignore; }
        self.closed = true;
        self.closing = true;
        self.activation.take().map_or(AfterClose::Exit, AfterClose::Activate)
    }

    pub fn close_timed_out(&self) -> bool { self.closing && !self.closed }
}

pub fn file_lock(name: &str, nonblocking: bool) -> Result<std::fs::File> {
    let file = std::fs::OpenOptions::new().create(true).truncate(false).read(true).write(true)
        .mode(0o600).open(runtime_dir()?.join(name))?;
    let operation = libc::LOCK_EX | if nonblocking { libc::LOCK_NB } else { 0 };
    if unsafe { libc::flock(file.as_raw_fd(), operation) } != 0 {
        return Err(std::io::Error::last_os_error().into());
    }
    Ok(file)
}

/// Prints one line per required Wayland global. Exits with status 1 if any is unusable.
fn check_compat() -> Result<()> {
    let statuses = wayland::probe_required_globals()?;
    for status in &statuses {
        println!("{status}");
    }
    if !statuses.iter().all(wayland::GlobalStatus::ok) {
        std::process::exit(1);
    }
    Ok(())
}

fn main() -> Result<()> {
    env_logger::init();
    let args = Args::parse();

    runtime_dir()?;
    if args.daemon { return wayland::run_daemon(); }
    if args.mru_check { wayland::ping()?; println!("MRU service OK"); return Ok(()); }
    if args.mru_list {
        println!("{}", serde_json::to_string_pretty(&wayland::snapshot(load_scope())?)?);
        return Ok(());
    }
    if args.check_compat {
        return check_compat();
    }

    let Some(owner) = ipc::claim_or_forward(&runtime_dir()?, args.reverse)? else {
        return Ok(());
    };
    let snapshot = wayland::snapshot(load_scope())?;
    if snapshot.toplevels.is_empty() { return Ok(()); }
    // Keep ownership through the full event loop and its renderer teardown.
    let result = app::run(snapshot.toplevels, args.reverse, snapshot.generation,
        load_theme(), owner.listener());
    drop(owner);
    result
}

//! Per-window activation history. Never identify windows by title or app_id.
use std::{cmp::Reverse, collections::HashMap};

#[derive(Default)]
pub struct History {
    clock: u64,
    windows: HashMap<u64, (bool, u64)>,
}
impl History {
    pub fn open(&mut self, id: u64) { self.windows.entry(id).or_insert((false, 0)); }
    pub fn close(&mut self, id: u64) { self.windows.remove(&id); }
    pub fn state(&mut self, id: u64, activated: bool) {
        let Some((was_active, last_used)) = self.windows.get_mut(&id) else { return; };
        if activated && !*was_active {
            self.clock += 1;
            *last_used = self.clock;
        }
        *was_active = activated;
    }
    pub fn sort_key(&self, id: u64) -> (Reverse<u64>, u64) {
        (Reverse(self.windows.get(&id).map(|w| w.1).unwrap_or(0)), id)
    }
}

const CELL_PAD:     u16 = 10;
const CELL_SPACING: u16 = 4;
const STRIP_PAD_X:  u16 = 18;
const STRIP_PAD_Y:  u16 = 14;
const TITLE_SIZE:   u16 = 14;
const TITLE_HEIGHT: u16 = 20;
const TITLE_GAP:    u16 = 6;
/// Breathing room around the strip, so its shadow isn't clipped by the surface edge.
const SURFACE_MARGIN: u32 = 40;

pub fn surface_size(window_count: usize, theme: &ThemeValues) -> (u32, u32) {
    let n = window_count as u32;
    let cell = u32::from(theme.icon_size) + 2 * u32::from(CELL_PAD);
    let strip_w = n * cell + n.saturating_sub(1) * u32::from(CELL_SPACING)
        + 2 * u32::from(STRIP_PAD_X);
    let strip_h = cell + u32::from(TITLE_GAP) + u32::from(TITLE_HEIGHT)
        + 2 * u32::from(STRIP_PAD_Y);
    (strip_w + SURFACE_MARGIN, strip_h + SURFACE_MARGIN)
}

fn fit_title(title: &str, surface_w: u32) -> String {
    let usable = surface_w
        .saturating_sub(SURFACE_MARGIN)
        .saturating_sub(2 * u32::from(STRIP_PAD_X));
    let max_chars = (usable / (u32::from(TITLE_SIZE) * 55 / 100)).max(3) as usize;
    if title.chars().count() <= max_chars {
        return title.to_string();
    }
    let kept: String = title.chars().take(max_chars.saturating_sub(1)).collect();
    format!("{}…", kept.trim_end())
}

pub fn view(state: &AppSwitcher) -> Element<'_, Message> {
    let tv = &state.theme;
    let (surface_w, surface_h) = surface_size(state.toplevels.len(), tv);

    if !state.lifecycle.visible() {
        return container(Space::new())
            .width(Length::Fixed(surface_w as f32))
            .height(Length::Fixed(surface_h as f32))
            .into();
    }

    let bg      = Color::from_rgba(tv.bg[0],          tv.bg[1],          tv.bg[2],          tv.bg[3]);
    let sel_bg  = Color::from_rgba(tv.selected_bg[0], tv.selected_bg[1], tv.selected_bg[2], tv.selected_bg[3]);
    let corner  = tv.corner_radius;
    let icon_sz = tv.icon_size;
    let cell_px = f32::from(icon_sz + 2 * CELL_PAD);

    let mut selected_label = String::new();

    let cells: Vec<Element<Message>> = state.visuals
        .iter()
        .enumerate()
        .map(|(i, visual)| {
            let selected = i == state.selected;
            if selected {
                selected_label = visual.label.clone();
            }

            let app_icon: Element<Message> = icon::icon(visual.handle.clone())
                .size(icon_sz)
                .content_fit(cosmic::iced::ContentFit::Contain)
                .width(Length::Fixed(f32::from(icon_sz)))
                .height(Length::Fixed(f32::from(icon_sz)))
                .into();

            let cell = container(app_icon)
                .width(Length::Fixed(cell_px))
                .height(Length::Fixed(cell_px))
                .center_x(Length::Fixed(cell_px))
                .center_y(Length::Fixed(cell_px))
                .padding(CELL_PAD)
                .style(move |_: &cosmic::Theme| {
                    if selected {
                        ContainerStyle {
                            background: Some(Background::Color(sel_bg)),
                            border: Border {
                                radius: (corner - 2.0).into(),
                                width: 0.0,
                                color: Color::TRANSPARENT,
                            },
                            ..Default::default()
                        }
                    } else {
                        ContainerStyle::default()
                    }
                });

            mouse_area(cell)
                .on_press(Message::SelectIndex(i))
                .on_release(Message::Activate)
                .into()
        })
        .collect();

    let fg = Color::from_rgba(tv.fg[0], tv.fg[1], tv.fg[2], tv.fg[3]);
    let title = text(fit_title(&selected_label, surface_w))
        .size(TITLE_SIZE)
        .height(TITLE_HEIGHT)

    let strip_h = surface_h.saturating_sub(SURFACE_MARGIN) as f32;

    let strip = container(
        column![
            row(cells).spacing(CELL_SPACING).align_y(Alignment::Center),
            title,
        ]
        .spacing(TITLE_GAP)
        .align_x(Alignment::Center)
    )
    .width(Length::Fixed(strip_w))
    .height(Length::Fixed(strip_h))
    .style(move |_: &cosmic::Theme| ContainerStyle {
        background: Some(Background::Color(bg)),
        border: Border {
            radius: corner.into(),
            width: 0.0,
            color: Color::TRANSPARENT,
        },
        shadow: Shadow {
            color: Color { r: 0.0, g: 0.0, b: 0.0, a: 0.6 },
            offset: Vector::new(0.0, 8.0),
            blur_radius: 32.0,
        },
        ..Default::default()
    })
    .padding([STRIP_PAD_Y, STRIP_PAD_X]);

    container(strip)
        .width(Length::Fixed(surface_w as f32))
        .height(Length::Fixed(surface_h as f32))
        .center_x(Length::Fixed(surface_w as f32))
        .center_y(Length::Fixed(surface_h as f32))
        .into()
}

        zcosmic_workspace_group_handle_v1::{self, ZcosmicWorkspaceGroupHandleV1},
        zcosmic_workspace_handle_v1::{self, ZcosmicWorkspaceHandleV1},
        zcosmic_workspace_manager_v1::{self, ZcosmicWorkspaceManagerV1},
    },
};
use switcher_config::WorkspaceScope;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ToplevelEntry {
    pub app_id:     String,
    pub title:      String,
    pub is_active:  bool,
    pub handle_key: u64,
}

#[derive(Serialize, Deserialize)]
pub struct Snapshot {
    pub generation: String,
    pub toplevels: Vec<ToplevelEntry>,
}

#[derive(Serialize, Deserialize)]
enum Request {
    List(WorkspaceScope),
    Activate { generation: String, key: u64 },
    Ping,
}

#[derive(Serialize, Deserialize)]
enum Response {
    List(Snapshot),
    Ok,
    Error(String),
}

pub fn daemon_socket_path() -> Result<std::path::PathBuf> {
    Ok(crate::runtime_dir()?.join("cosmic-ext-app-switcher-mru.sock"))
}

fn request(request: &Request) -> Result<Response> {
    let mut stream = UnixStream::connect(daemon_socket_path()?)
        .context("MRU service is not running. Run: systemctl --user restart cosmic-ext-app-switcher-mru.service")?;
    stream.set_read_timeout(Some(Duration::from_secs(2)))?;
    stream.set_write_timeout(Some(Duration::from_secs(2)))?;
    serde_json::to_writer(&mut stream, request)?;
    stream.shutdown(std::net::Shutdown::Write)?;
    let mut bytes = Vec::new();
    stream.take(4 * 1024 * 1024).read_to_end(&mut bytes)?;
    let reply: Response = serde_json::from_slice(&bytes)?;
    if let Response::Error(message) = &reply { return Err(anyhow!("{message}")); }
    Ok(reply)
}

pub fn snapshot(scope: WorkspaceScope) -> Result<Snapshot> {
    check_scope(scope)?;
    match request(&Request::List(scope))? {
        Response::List(snapshot) => Ok(snapshot),
        _ => Err(anyhow!("Unexpected MRU service response")),
    }
}

fn check_scope(scope: WorkspaceScope) -> Result<()> {
    if scope == WorkspaceScope::CurrentWorkspace {
        return Err(anyhow!("Current workspace is unsupported by the pinned legacy Wayland protocol. Choose All workspaces or Current monitor in the switcher settings."));
    }
    Ok(())
}

pub fn activate(generation: &str, key: u64) -> Result<()> {
    match request(&Request::Activate { generation: generation.into(), key })? {
        Response::Ok => Ok(()),
        _ => Err(anyhow!("Unexpected MRU activation response")),
    }
}

pub fn ping() -> Result<()> {
    match request(&Request::Ping)? {
        Response::Ok => Ok(()),
        _ => Err(anyhow!("Unexpected MRU health response")),
    }
}

// Versions we bind at. The compositor has to keep speaking the version a client bound, so
// newer versions it adds later don't affect us. zcosmic_toplevel_info_v1 must stay at 1:
// v2+ never emits Toplevel events.
const TOPLEVEL_INFO_VERSION:    u32 = 1;
const TOPLEVEL_MANAGER_VERSION: u32 = 1;
const SEAT_VERSION:             u32 = 7;

/// Globals the switcher can't work without, and the lowest version of each it accepts.
/// zwlr_layer_shell_v1 is bound by libcosmic on its own connection (for the overlay), not
/// by us, but cosmic-comp gates it the same way as the toplevel protocols, so it's checked
/// here too. libcosmic's toolkit accepts any version from 1.
const REQUIRED_GLOBALS: &[(&str, u32)] = &[
    ("zcosmic_toplevel_info_v1",    TOPLEVEL_INFO_VERSION),
    ("zcosmic_toplevel_manager_v1", TOPLEVEL_MANAGER_VERSION),
    ("zwlr_layer_shell_v1",         1),
    ("wl_seat",                     SEAT_VERSION),
];

pub struct GlobalStatus {
    interface:  &'static str,
    needed:     u32,
    advertised: Option<u32>,  // highest version offered, None if not offered at all
}

impl GlobalStatus {
    pub fn ok(&self) -> bool {
        self.advertised.is_some_and(|v| v >= self.needed)
    }
}

impl std::fmt::Display for GlobalStatus {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        let (interface, needed) = (self.interface, self.needed);
        match self.advertised {
            Some(v) if v >= needed => write!(f, "{interface}: ok (v{v}, needs v{needed})"),
            Some(v) => write!(f, "{interface}: TOO OLD (v{v}, needs v{needed})"),
            None    => write!(f, "{interface}: NOT offered (needs v{needed})"),
        }
    }
}

fn required_globals_status(advertised: &[(String, u32)]) -> Vec<GlobalStatus> {
    REQUIRED_GLOBALS.iter()
        .map(|&(interface, needed)| GlobalStatus {
            interface,
            needed,
            advertised: advertised.iter()
                .filter(|(i, _)| i == interface)
                .map(|&(_, v)| v)
                .max(),
        })
        .collect()
}

/// Connects to the compositor and reports on every required global, for `--check-compat`.
pub fn probe_required_globals() -> Result<Vec<GlobalStatus>> {
    let conn = Connection::connect_to_env()
        .context("could not connect to the Wayland compositor (is COSMIC running?)")?;
    let (globals, _queue) = registry_queue_init::<RegistryProbe>(&conn)?;
    let advertised: Vec<(String, u32)> = globals.contents().clone_list()
        .into_iter()
        .map(|g| (g.interface, g.version))
        .collect();
    Ok(required_globals_status(&advertised))
}

struct AppData {
    history: History,
    next_key: u64,
    generation: String,
    toplevels:          Vec<Toplevel>,
    _info:              Option<ZcosmicToplevelInfoV1>,  // must stay alive to receive events
    manager:            Option<ZcosmicToplevelManagerV1>,
    seat:               Option<wl_seat::WlSeat>,
    _workspace_manager: Option<ZcosmicWorkspaceManagerV1>,
    outputs:            Vec<wl_output::WlOutput>,
    // cosmic-comp does a one-time sync of each toplevel's output membership at handle
    // creation time, using whatever wl_output binds the client already has — so we must
    // not bind zcosmic_toplevel_info_v1 (which creates toplevel handles) until our own
    // wl_output binds have been sent first. Deferred here and bound explicitly after the
    // registry listing is fully drained, rather than reactively as its Global arrives.
    toplevel_info_name: Option<u32>,
    globals:            Vec<(String, u32)>,  // every (interface, version) advertised
}

struct Toplevel {
    key: u64,
    handle:     ZcosmicToplevelHandleV1,
    app_id:     String,
    title:      String,
    is_active:  bool,
    outputs:    Vec<wl_output::WlOutput>,
    workspaces: Vec<ZcosmicWorkspaceHandleV1>,
}

pub fn run_daemon() -> Result<()> {
    // Lock before removing a stale socket, so a second daemon cannot steal it.
    let _lock = crate::file_lock("cosmic-ext-app-switcher-mru.lock", true)?;
    let conn    = Connection::connect_to_env()?;
    let display = conn.display();
    let mut queue = conn.new_event_queue();
    let qh = queue.handle();

    let registry = display.get_registry(&qh, ());

    let mut data = AppData {
        history: History::default(),
        next_key: 0,
        generation: format!("{}-{}", std::process::id(), SystemTime::now().duration_since(UNIX_EPOCH)?.as_nanos()),
        toplevels: vec![],
        _info: None,
        manager: None,
        seat: None,
        _workspace_manager: None,
        outputs: vec![],
        toplevel_info_name: None,
        globals: vec![],
    };

    // First roundtrip: drain the full registry listing. wl_output/wl_seat/workspace-manager
    // are bound immediately as their Globals arrive; zcosmic_toplevel_info_v1's bind is
    // deferred (see AppData::toplevel_info_name) regardless of where in the listing it
    // appears.
    queue.roundtrip(&mut data)?;

    // Without this, a missing global means an empty window list and a silent exit (or an
    // overlay whose selection can't be activated), which looks like a bug in the switcher.
    let missing: Vec<String> = required_globals_status(&data.globals).iter()
        .filter(|s| !s.ok())
        .map(ToString::to_string)
        .collect();
    if !missing.is_empty() {
        return Err(anyhow!(
            "cosmic-ext-app-switcher can't run: the compositor doesn't offer the Wayland \
             interfaces it needs ({}). A COSMIC update may have removed or changed them, or \
             the switcher is running inside a sandbox such as Flatpak. Run \
             `cosmic-ext-app-switcher --check-compat` for details.",
            missing.join("; "),
        ));
    }

    // Second roundtrip: force the server to fully process our wl_output bind requests
    // before we bind toplevel_info below — otherwise toplevel handles it creates may miss
    // their initial output_enter sync (see comment on toplevel_info_name).
    queue.roundtrip(&mut data)?;

    if let Some(name) = data.toplevel_info_name.take() {
        data._info = Some(
            registry.bind::<ZcosmicToplevelInfoV1, _, _>(name, TOPLEVEL_INFO_VERSION, &qh, ())
        );
    }

    // Extra roundtrips over the original three: workspace-group/workspace handles and
    // toplevel handles both need time to fully cascade before we read state back out.
    for _ in 0..5 {
        queue.roundtrip(&mut data)?;
    }

    let path = daemon_socket_path()?;
    let _ = std::fs::remove_file(&path);
    let listener = UnixListener::bind(&path)?;
    std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600))?;
    listener.set_nonblocking(true)?;
    let _cleanup = crate::ipc::OwnedSocket::new(path)?;
    log::info!("MRU service ready; history starts now");

    loop {
        queue.dispatch_pending(&mut data)?;
        conn.flush()?;
        let Some(guard) = queue.prepare_read() else { continue; };
        let mut fds = [
            libc::pollfd { fd: conn.backend().poll_fd().as_raw_fd(), events: libc::POLLIN, revents: 0 },
            libc::pollfd { fd: listener.as_raw_fd(), events: libc::POLLIN, revents: 0 },
        ];
        // No periodic polling: sleep until the compositor or a client has an event.
        let ready = unsafe { libc::poll(fds.as_mut_ptr(), fds.len() as libc::nfds_t, -1) };
        if ready < 0 {
            drop(guard);
            let error = std::io::Error::last_os_error();
            if error.kind() == std::io::ErrorKind::Interrupted { continue; }
            return Err(error.into());
        }
        if fds.iter().any(|fd| fd.revents & (libc::POLLERR | libc::POLLHUP | libc::POLLNVAL) != 0) {
            return Err(anyhow!("Wayland connection or MRU socket closed/failed"));
        }
        if fds[0].revents != 0 {
            guard.read()?;
            queue.dispatch_pending(&mut data)?;
        } else { drop(guard); }
        if fds[1].revents & libc::POLLIN != 0 {
            let (mut stream, _) = match listener.accept() {
                Ok(client) => client,
                Err(error) if matches!(error.kind(), std::io::ErrorKind::WouldBlock | std::io::ErrorKind::Interrupted) => continue,
                Err(error) => return Err(error.into()),
            };
            // Clients are same-user only. Bound reads so an interrupted client cannot hang us.
            stream.set_read_timeout(Some(Duration::from_millis(500)))?;
            stream.set_write_timeout(Some(Duration::from_millis(500)))?;
            let mut bytes = Vec::new();
            if (&mut stream).take(65536).read_to_end(&mut bytes).is_err() { continue; }
            let reply = match serde_json::from_slice::<Request>(&bytes) {
                Ok(Request::List(scope)) => {
                    if let Err(error) = check_scope(scope) {
                        Response::Error(error.to_string())
                    } else {
                        // Drain focus events before freezing the UI snapshot.
                        queue.roundtrip(&mut data)?;
                        Response::List(data.snapshot(scope))
                    }
                }
                Ok(Request::Activate { generation, key }) => {
                    queue.roundtrip(&mut data)?;
                    if generation != data.generation {
                        Response::Error("MRU service restarted; reopen Alt+Tab".into())
                    } else if let Some(t) = data.toplevels.iter().find(|t| t.key == key) {
                        if let (Some(manager), Some(seat)) = (&data.manager, &data.seat) {
                            manager.activate(&t.handle, seat);
                            // Flush and acknowledge server processing before the UI can exit.
                            // History changes ONLY on compositor-confirmed Activated events.
                            queue.roundtrip(&mut data)?;
                            Response::Ok
                        } else { Response::Error("Activation protocol unavailable".into()) }
                    } else { Response::Error("Selected window has already closed".into()) }
                }
                Ok(Request::Ping) => Response::Ok,
                Err(error) => Response::Error(error.to_string()),
            };
            // A closed UI must not terminate the background service.
            let _ = serde_json::to_writer(&mut stream, &reply);
            let _ = stream.flush();
        }
    }
}

impl AppData {
    fn snapshot(&self, scope: WorkspaceScope) -> Snapshot {
        let reference = self.toplevels.iter()
            .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
            .min_by_key(|t| self.history.sort_key(t.key));
        let active_outputs = reference.map(|t| t.outputs.as_slice()).unwrap_or(&[]);
        let mut entries: Vec<_> = self.toplevels.iter()
            .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
            .filter(|t| match scope {
                WorkspaceScope::AllWorkspaces => true,
                // Rejected by check_scope before reaching this filter.
                WorkspaceScope::CurrentWorkspace => false,
                WorkspaceScope::CurrentOutput => active_outputs.is_empty()
                    || t.outputs.iter().any(|o| active_outputs.contains(o)),
            })
            .map(|t| ToplevelEntry {
                app_id: t.app_id.clone(), title: t.title.clone(),
                is_active: t.is_active, handle_key: t.key,
            }).collect();
        entries.sort_by_key(|t| self.history.sort_key(t.handle_key));
        Snapshot { generation: self.generation.clone(), toplevels: entries }
    }
}

// --- Registry: bind our three globals ---

impl Dispatch<wl_registry::WlRegistry, ()> for AppData {
    fn event(
        data: &mut Self,
        registry: &wl_registry::WlRegistry,
        event: wl_registry::Event,
        _: &(),
        _: &Connection,
        qh: &QueueHandle<Self>,
    ) {
        if let wl_registry::Event::Global { name, interface, version } = event {
            data.globals.push((interface.clone(), version));
            // A global offered below the version we bind is left unbound: binding it would
            // be a protocol error that kills the connection before the required-globals
            // check in wayland_thread_main can report it.
            match interface.as_str() {
                "zcosmic_toplevel_info_v1" if version >= TOPLEVEL_INFO_VERSION => {
                    // Binding deferred until after wl_output is bound — see
                    // AppData::toplevel_info_name and wayland_thread_main.
                    data.toplevel_info_name = Some(name);
                }
                "zcosmic_toplevel_manager_v1" if version >= TOPLEVEL_MANAGER_VERSION => {
                    data.manager = Some(registry.bind::<ZcosmicToplevelManagerV1, _, _>(
                        name, TOPLEVEL_MANAGER_VERSION, qh, (),
                    ));
                }
                "wl_seat" if version >= SEAT_VERSION => {
                    if data.seat.is_none() {
                        data.seat = Some(
                            registry.bind::<wl_seat::WlSeat, _, _>(name, SEAT_VERSION, qh, ())
                        );
                    }
                }
                "wl_output" => {
                    data.outputs.push(
                        registry.bind::<wl_output::WlOutput, _, _>(name, 1, qh, ())
                    );
                }
                "zcosmic_workspace_manager_v1" => {
                    data._workspace_manager = Some(
                        registry.bind::<ZcosmicWorkspaceManagerV1, _, _>(name, 1, qh, ())
                    );
                }
                _ => {}
            }
        }
    }
}

// --- ZcosmicToplevelInfoV1: new toplevel events ---

impl Dispatch<ZcosmicToplevelInfoV1, ()> for AppData {
    fn event(
        data: &mut Self,
        _: &ZcosmicToplevelInfoV1,
        event: zcosmic_toplevel_info_v1::Event,
        _: &(),
        _: &Connection,
        _: &QueueHandle<Self>,
    ) {
        if let zcosmic_toplevel_info_v1::Event::Toplevel { toplevel } = event {
            data.next_key += 1;
            data.history.open(data.next_key);
            data.toplevels.push(Toplevel {
                key: data.next_key,
                handle:     toplevel,
                app_id:     String::new(),
                title:      String::new(),
                is_active:  false,
                outputs:    vec![],
                workspaces: vec![],
            });
        }
    }

    event_created_child!(AppData, ZcosmicToplevelInfoV1, [
        zcosmic_toplevel_info_v1::EVT_TOPLEVEL_OPCODE =>
            (ZcosmicToplevelHandleV1, ()),
    ]);
}

// --- ZcosmicToplevelHandleV1: per-window metadata ---

impl Dispatch<ZcosmicToplevelHandleV1, ()> for AppData {
    fn event(
        data: &mut Self,
        handle: &ZcosmicToplevelHandleV1,
        event: zcosmic_toplevel_handle_v1::Event,
        _: &(),
        _: &Connection,
        _: &QueueHandle<Self>,
    ) {
        let Some(t) = data.toplevels.iter_mut().find(|t| &t.handle == handle) else {
            return;
        };
        match event {
            zcosmic_toplevel_handle_v1::Event::AppId { app_id } => {
                t.app_id = app_id;
            }
            zcosmic_toplevel_handle_v1::Event::Title { title } => {
                t.title = title;
            }
            zcosmic_toplevel_handle_v1::Event::State { state } => {
                let activated = zcosmic_toplevel_handle_v1::State::Activated as u32;
                t.is_active = state
                    .chunks_exact(4)
                    .any(|b| u32::from_ne_bytes(b.try_into().unwrap()) == activated);
                data.history.state(t.key, t.is_active);
            }
            zcosmic_toplevel_handle_v1::Event::Closed => {
                data.history.close(t.key);
                data.toplevels.retain(|t| &t.handle != handle);
            }
            zcosmic_toplevel_handle_v1::Event::OutputEnter { output } => {
                if !t.outputs.contains(&output) {
                    t.outputs.push(output);
                }
            }
            zcosmic_toplevel_handle_v1::Event::OutputLeave { output } => {
                t.outputs.retain(|o| o != &output);
            }
            zcosmic_toplevel_handle_v1::Event::WorkspaceEnter { workspace } => {
                if !t.workspaces.contains(&workspace) {
                    t.workspaces.push(workspace);
                }
            }
            zcosmic_toplevel_handle_v1::Event::WorkspaceLeave { workspace } => {
                t.workspaces.retain(|w| w != &workspace);
            }
            _ => {}
        }
    }
}

#[cfg(test)]
mod tests {
    use super::required_globals_status;

    #[test]
    fn unsupported_workspace_scope_cannot_silently_return_all_windows() {
        use switcher_config::WorkspaceScope;
        assert!(super::check_scope(WorkspaceScope::CurrentWorkspace).is_err());
        assert!(super::check_scope(WorkspaceScope::AllWorkspaces).is_ok());
        assert!(super::check_scope(WorkspaceScope::CurrentOutput).is_ok());
    }

    fn advertised(globals: &[(&str, u32)]) -> Vec<(String, u32)> {
        globals.iter().map(|&(i, v)| (i.to_string(), v)).collect()
    }

    fn line_for(globals: &[(&str, u32)], interface: &str) -> String {
        required_globals_status(&advertised(globals)).iter()
            .map(ToString::to_string)
            .find(|l| l.starts_with(&format!("{interface}:")))
            .unwrap()
    }

    #[test]
    fn everything_offered_is_ok() {
        let globals = [
            ("zcosmic_toplevel_info_v1", 3),
            ("zcosmic_toplevel_manager_v1", 4),
            ("zwlr_layer_shell_v1", 5),
            ("wl_seat", 9),
        ];
        assert!(required_globals_status(&advertised(&globals)).iter().all(|s| s.ok()));
    }

    #[test]
    fn missing_global_is_reported() {
        let globals = [("zcosmic_toplevel_info_v1", 3), ("zwlr_layer_shell_v1", 5), ("wl_seat", 9)];
        let statuses = required_globals_status(&advertised(&globals));
        assert_eq!(statuses.iter().filter(|s| !s.ok()).count(), 1);
        assert_eq!(
            line_for(&globals, "zcosmic_toplevel_manager_v1"),
            "zcosmic_toplevel_manager_v1: NOT offered (needs v1)",
        );
    }

    #[test]
    fn version_below_the_one_we_bind_is_too_old() {
        let globals = [("wl_seat", 5)];
        assert_eq!(line_for(&globals, "wl_seat"), "wl_seat: TOO OLD (v5, needs v7)");
    }

    /// A seat advertised twice counts as its highest version.
    #[test]
    fn repeated_global_uses_highest_version() {
        let globals = [("wl_seat", 5), ("wl_seat", 8)];
        assert_eq!(line_for(&globals, "wl_seat"), "wl_seat: ok (v8, needs v7)");
    }
}

fn shortcuts_config_path() -> Option<std::path::PathBuf> {
    let config_home = std::env::var("XDG_CONFIG_HOME")
        .map(std::path::PathBuf::from)
        .unwrap_or_else(|_| {
            std::path::PathBuf::from(std::env::var("HOME").unwrap_or_default()).join(".config")
        });

    let shortcuts_dir = config_home
        .join("cosmic")
        .join("com.system76.CosmicSettings.Shortcuts");

    if !shortcuts_dir.exists() {
        return None;
    }

    // Mirror find-config.sh: find existing system_actions in highest version dir.
    if let Ok(entries) = std::fs::read_dir(&shortcuts_dir) {
        let mut version_dirs: Vec<_> = entries
            .filter_map(|e| e.ok())
            .filter(|e| e.path().is_dir() && e.file_name().to_string_lossy().starts_with('v'))
            .map(|e| e.path())
            .collect();
        version_dirs.sort_by_key(|p| {
            p.file_name()
                .and_then(|n| {
                    let s = n.to_string_lossy();
                    s.strip_prefix('v').and_then(|v| v.parse::<u32>().ok())
                })
                .unwrap_or(0)
        });

        for dir in version_dirs.iter().rev() {
            let p = dir.join("system_actions");
            if p.exists() {
                return Some(p);
            }
        }

        if let Some(latest) = version_dirs.last() {
            return Some(latest.join("system_actions"));
        }
    }

    Some(shortcuts_dir.join("v1").join("system_actions"))
}

fn shortcut_is_configured() -> bool {
    shortcuts_config_path()
        .and_then(|p| std::fs::read_to_string(p).ok())
        .map(|s| s.contains("cosmic-ext-app-switcher") || s.contains("cosmic-app-switcher"))
        .unwrap_or(false)
}

fn switcher_exec() -> String {
    if std::env::var("FLATPAK_ID").is_ok() {
        format!("flatpak run --command=cosmic-ext-app-switcher {APPLET_ID}")
    } else {
        let home = std::env::var("HOME").unwrap_or_default();
        format!("{home}/.local/bin/cosmic-ext-app-switcher")
    }
}

/// Rebuild the `system_actions` RON map: every entry except our two keys, wrapped in a
/// fresh pair of braces, with our entries appended when `cmd` is `Some`.
///
/// Rebuilding rather than splicing is what keeps degenerate inputs safe — an empty file
/// or a single-line `{}` used to produce a body with no opening brace. That doesn't fail
/// loudly: cosmic-settings-daemon logs a parse error and falls back to the packaged
/// defaults, so the user's other overrides quietly stop working (issue #10). Mirrors
/// scripts/shortcut-config.sh.
fn rebuild_shortcut_map(existing: Option<&str>, cmd: Option<&str>) -> String {
    let mut out = String::from("{\n");

    for line in existing.unwrap_or_default().lines() {
        let t = line.trim();
        if t.is_empty() || t == "{" || t == "}" || t == "{}" {
            continue;
        }
        if t.starts_with("WindowSwitcher:") || t.starts_with("WindowSwitcherPrevious:") {
            continue;
        }
        out.push_str(line);
        out.push('\n');
    }

    if let Some(cmd) = cmd {
        out.push_str(&format!("    WindowSwitcher: \"{cmd}\",\n"));
        out.push_str(&format!("    WindowSwitcherPrevious: \"{cmd} --reverse\",\n"));
    }

    out.push('}');
    out.push('\n');
    out
}

fn write_shortcut_map(path: &std::path::Path, content: String) -> Result<(), String> {
    if !content.starts_with('{') || !content.trim_end().ends_with('}') {
        return Err("refusing to write malformed shortcut config".to_string());
    }
    std::fs::write(path, content).map_err(|e| e.to_string())?;
    // cosmic-config writes these 0600; keep that when we create the file ourselves.
    use std::os::unix::fs::PermissionsExt;
    let _ = std::fs::set_permissions(path, std::fs::Permissions::from_mode(0o600));
    Ok(())
}

fn do_unregister_shortcut() -> Result<(), String> {
    let path = match shortcuts_config_path() {
        Some(p) => p,
        None => return Ok(()),
    };
    if !path.exists() {
        return Ok(());
    }
    let content = std::fs::read_to_string(&path).map_err(|e| e.to_string())?;
    write_shortcut_map(&path, rebuild_shortcut_map(Some(&content), None))
}

fn do_register_shortcut() -> Result<(), String> {
    let path = shortcuts_config_path()
        .ok_or_else(|| "COSMIC shortcuts directory not found — is COSMIC installed?".to_string())?;

    let existing = std::fs::read_to_string(&path).ok();
    if existing.as_deref().is_some_and(|s| s.contains("cosmic-ext-app-switcher")) {
        return Ok(());
    }

    std::fs::create_dir_all(path.parent().unwrap())
        .map_err(|e| e.to_string())?;

    let cmd = switcher_exec();
    write_shortcut_map(&path, rebuild_shortcut_map(existing.as_deref(), Some(&cmd)))
}

impl Application for AppletApp {
    type Executor = cosmic::executor::Default;
    type Flags    = ();
    type Message  = Message;

    const APP_ID: &'static str = APPLET_ID;

    fn core(&self) -> &Core { &self.core }
    fn core_mut(&mut self) -> &mut Core { &mut self.core }

    fn init(core: Core, _flags: ()) -> (Self, Task<Message>) {
        let config_handler = cosmic::cosmic_config::Config::new(APP_ID, CONFIG_VERSION).ok();
        let current_theme  = config_handler
            .as_ref()
            .and_then(|c| c.get::<Theme>("theme").ok())
            .unwrap_or_default();
        let current_scope  = config_handler
            .as_ref()
            .and_then(|c| c.get::<WorkspaceScope>("workspace_scope").ok())
            .unwrap_or_default();

        (
            Self {
                core,
                popup: None,
                current_theme,
                current_scope,
                config_handler,
                shortcut_configured: shortcut_is_configured(),
                shortcut_error: None,
            },
            Task::none(),
        )
    }

    fn style(&self) -> Option<cosmic::iced::theme::Style> {
        Some(cosmic::applet::style())
    }

    fn on_close_requested(&self, id: WindowId) -> Option<Message> {
        Some(Message::PopupClosed(id))
    }

    fn update(&mut self, message: Message) -> Task<Message> {
        match message {
            Message::TogglePopup => {
                if let Some(popup_id) = self.popup.take() {
                    return destroy_popup(popup_id);
                }
                let new_id = WindowId::unique();
                self.popup = Some(new_id);
                let popup_settings = self.core.applet.get_popup_settings(
                    self.core.main_window_id().unwrap(),
                    new_id,
                    None,
                    None,
                    None,
                );
                return get_popup(popup_settings);
            }
            Message::PopupClosed(id) => {
                if self.popup == Some(id) {
                    self.popup = None;
                }
            }
            Message::SetTheme(theme) => {
                if let Some(handler) = &self.config_handler {
                    let _ = handler.set("theme", &theme);
                }
                self.current_theme = theme;
            }
            Message::SetScope(scope) => {
                if let Some(handler) = &self.config_handler {
                    let _ = handler.set("workspace_scope", &scope);
                }
                self.current_scope = scope;
            }
            Message::ToggleShortcut(enable) => {
                let result = if enable {
                    do_register_shortcut()
                } else {
                    do_unregister_shortcut()
                };
                match result {
                    Ok(()) => {
                        self.shortcut_configured = enable;
                        self.shortcut_error = None;
                    }
                    Err(e) => self.shortcut_error = Some(e),
                }
            }
        }
        Task::none()
    }

    fn view(&self) -> Element<Message> {
        let mut handle = cosmic::widget::icon::from_svg_bytes(
            include_bytes!("../data/io.github.cosmic-ext-applet-app-switcher-symbolic.svg")
                as &'static [u8],
        );
        handle.symbolic = true;
        self.core
            .applet
            .icon_button_from_handle(handle)
            .on_press(Message::TogglePopup)
            .into()
    }

    fn view_window(&self, _id: WindowId) -> Element<Message> {
        let swatches: Vec<Element<Message>> = Theme::all()
            .into_iter()
            .map(|t| {
                let preview_bg = {
                    let p = t.preview_bg();
                    Color::from_rgb(p[0], p[1], p[2])
                };
                let selected = t == self.current_theme;
                let label = t.label().to_string();
                let t_clone = t.clone();

                let swatch = container(
                    cosmic::widget::Space::new()
                )
                .width(Length::Fixed(68.0))
                .height(Length::Fixed(40.0))
                .style(move |_: &cosmic::Theme| ContainerStyle {
                    background: Some(Background::Color(preview_bg)),
                    border: Border {
                        radius: 6.0.into(),
                        width: if selected { 2.5 } else { 0.0 },
                        color: Color::from_rgb(0.38, 0.58, 1.0),
                    },
                    ..Default::default()
                });

                let card = column![
                    swatch,
                    text(label).size(11),
                ]
                .spacing(4)
                .align_x(Alignment::Center);

                mouse_area(card)
                    .on_press(Message::SetTheme(t_clone))
                    .into()
            })
            .collect();

        let scope_options: Vec<Element<Message>> = WorkspaceScope::all()
            .into_iter()
            .map(|s| {
                let selected = s == self.current_scope;
                let label = s.label().to_string();

                let card = container(text(label).size(12))
                    .padding([6, 10])
                    .style(move |_: &cosmic::Theme| ContainerStyle {
                        border: Border {
                            radius: 6.0.into(),
                            width: if selected { 2.0 } else { 1.0 },
                            color: if selected {
                                Color::from_rgb(0.38, 0.58, 1.0)
                            } else {
                                Color::from_rgba(1.0, 1.0, 1.0, 0.15)
                            },
                        },
                        ..Default::default()
                    });

                mouse_area(card).on_press(Message::SetScope(s)).into()
            })
            .collect();

        let flatpak_note: Option<Element<Message>> = std::env::var("FLATPAK_ID").ok().map(|_| {
            // Nothing of ours runs at `flatpak uninstall`, so a shortcut left registered
            // keeps Super+Tab pointing at a command that no longer exists — and COSMIC
            // does not fall back to its built-in switcher (issue #10).
            text("Flatpak: turn this off before uninstalling, or Super+Tab stays bound to a removed app.")
                .size(10)
                .into()
        });

        let shortcut_row = row![
            text("Super+Tab shortcut").size(14),
            cosmic::widget::Space::new().width(Length::Fill),
            cosmic::widget::toggler(self.shortcut_configured)
                .on_toggle(Message::ToggleShortcut),
        ]
        .align_y(Alignment::Center);

        let mut shortcut_section = column![shortcut_row].spacing(6);
        if let Some(note) = flatpak_note {
            shortcut_section = shortcut_section.push(note);
        }

        let mut content = column![
            shortcut_section,
            cosmic::widget::divider::horizontal::default(),
            text("Theme").size(14),
            row(swatches).spacing(12),
            cosmic::widget::divider::horizontal::default(),
            text("Switch scope").size(14),
            row(scope_options).spacing(8),
            // Shown so bug reports can name a version — see the release checklist in
            // .claude/CLAUDE.md.
            text(format!("v{}", env!("CARGO_PKG_VERSION"))).size(10),
        ]
        .spacing(12)
        .padding(16)
        .align_x(Alignment::Center);

        if let Some(err) = &self.shortcut_error {
            content = column![content, text(format!("Error: {err}")).size(10)]
                .spacing(4)
                .align_x(Alignment::Center);
        }

        self.core.applet.popup_container(content).into()
    }
}

#[cfg(test)]
mod tests {
    use super::rebuild_shortcut_map;

    const CMD: &str = "/home/u/.local/bin/cosmic-ext-app-switcher";

    fn assert_well_formed(s: &str) {
        assert!(s.starts_with("{\n"), "missing opening brace: {s:?}");
        assert!(s.ends_with("}\n"), "missing closing brace: {s:?}");
    }

    /// The inputs that used to yield a body with no opening brace.
    #[test]
    fn degenerate_inputs_stay_well_formed() {
        for existing in [None, Some(""), Some("{}"), Some("{}\n"), Some("{\n}\n"), Some("\n\n")] {
            let out = rebuild_shortcut_map(existing, Some(CMD));
            assert_well_formed(&out);
            assert_eq!(out.matches("WindowSwitcher:").count(), 1, "for {existing:?}");
        }
    }

    #[test]
    fn other_entries_are_preserved() {
        let existing = "{\n    Terminal: \"ghostty\",\n    WebBrowser: \"firefox\",\n}\n";
        let out = rebuild_shortcut_map(Some(existing), Some(CMD));
        assert_well_formed(&out);
        assert!(out.contains("Terminal: \"ghostty\""));
        assert!(out.contains("WebBrowser: \"firefox\""));
        assert!(out.contains(&format!("WindowSwitcher: \"{CMD}\"")));
        assert!(out.contains(&format!("WindowSwitcherPrevious: \"{CMD} --reverse\"")));
    }

    #[test]
    fn existing_bindings_are_replaced_not_duplicated() {
        let existing = "{\n    WindowSwitcher: \"/old\",\n    WindowSwitcherPrevious: \"/old --reverse\",\n}\n";
        let out = rebuild_shortcut_map(Some(existing), Some(CMD));
        assert_eq!(out.matches("WindowSwitcher:").count(), 1);
        assert_eq!(out.matches("WindowSwitcherPrevious:").count(), 1);
        assert!(!out.contains("/old"));
    }

    #[test]
    fn unregister_leaves_a_valid_map() {
        let existing = "{\n    Terminal: \"ghostty\",\n    WindowSwitcher: \"x\",\n    WindowSwitcherPrevious: \"x --reverse\",\n}\n";
        let out = rebuild_shortcut_map(Some(existing), None);
        assert_well_formed(&out);
        assert!(!out.contains("WindowSwitcher"));
        assert!(out.contains("Terminal: \"ghostty\""));

        // …and an empty map when we were the only entry.
        let only_ours = "{\n    WindowSwitcher: \"x\",\n}\n";
        assert_eq!(rebuild_shortcut_map(Some(only_ours), None), "{\n}\n");
    }
}

#!/usr/bin/env python3
"""Čitelná kopie Rustových zdrojů z Python instalátorů; nic neinstaluje.

Spuštění na macOS i Linuxu:
  python3 "alt tab/tools/rozbalit_payloady.py"
  python3 "alt tab/tools/rozbalit_payloady.py" --check

Instalátory pouze parsuje pomocí AST, neimportuje je ani nespouští.
Existující odlišný soubor nepřepíše. Kopie nejsou automaticky baleny zpět.
"""

import argparse
import ast
import base64
import hashlib
import io
import json
from pathlib import Path, PurePosixPath
import tarfile


ROOT = Path(__file__).resolve().parents[1]
SOURCES = {
    "ver-1.1-install": "ver 1.1/cosmic_alt_tab_mru_install.py",
    "ver-1.1-fixed": "ver 1.1/cosmic_alt_tab_mru_fixed.py",
}


def sha256(data):
    return hashlib.sha256(data).hexdigest()


def read_payload(source):
    raw = source.read_bytes()
    values = {}
    for node in ast.parse(raw, filename=str(source)).body:
        if isinstance(node, ast.Assign):
            for target in node.targets:
                if isinstance(target, ast.Name) and target.id in {"PAYLOAD", "PAYLOAD_SHA256"}:
                    values[target.id] = ast.literal_eval(node.value)
    payload = base64.b64decode("".join(values["PAYLOAD"].split()), validate=True)
    if sha256(payload) != values["PAYLOAD_SHA256"]:
        raise ValueError(f"Nesouhlasí kontrolní součet payloadu: {source}")

    files = {}
    with tarfile.open(fileobj=io.BytesIO(payload), mode="r:gz") as archive:
        for member in archive.getmembers():
            name = PurePosixPath(member.name)
            if name.is_absolute() or ".." in name.parts or not name.parts:
                raise ValueError(f"Neplatná cesta v archivu: {member.name}")
            if not (member.isfile() or member.isdir()):
                raise ValueError(f"Nepodporovaný typ položky: {member.name}")
            if member.isfile():
                key = name.as_posix()
                if key in files:
                    raise ValueError(f"Duplicitní soubor: {key}")
                with archive.extractfile(member) as content:
                    files[key] = content.read()

    manifest = {
        "source_installer": source.relative_to(ROOT).as_posix(),
        "source_installer_sha256": sha256(raw),
        "payload_sha256": sha256(payload),
        "format": "base64 -> gzip -> tar -> Rust source project",
        "files": {name: sha256(data) for name, data in sorted(files.items())},
    }
    files["PAYLOAD-PUVOD.json"] = (json.dumps(manifest, ensure_ascii=False, indent=2) + "\n").encode()
    return files


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--check", action="store_true", help="Pouze ověří shodu kopií s payloady")
    args = parser.parse_args()

    pending = []
    for name, relative in SOURCES.items():
        destination = ROOT / "rozbalene-zdroje" / name
        files = read_payload(ROOT / relative)
        for filename, content in files.items():
            target = destination / filename
            if any(p.is_symlink() for p in (target, *target.parents) if p != ROOT and ROOT in p.parents):
                raise ValueError(f"Cíl nesmí vést přes symbolický odkaz: {target}")
            if target.exists():
                if not target.is_file() or target.read_bytes() != content:
                    raise ValueError(f"Kopie se liší; nepřepisuji: {target}")
            elif args.check:
                raise ValueError(f"Chybí kopie: {target}")
            else:
                pending.append((target, content))
        if destination.exists():
            extra = {p.relative_to(destination).as_posix() for p in destination.rglob("*") if not p.is_dir()} - files.keys()
            if extra:
                raise ValueError(f"Neočekávané soubory v {destination}: {sorted(extra)}")
        print(f"{name}: ověřeno {len(files) - 1} souborů a původ payloadu")

    for target, content in pending:
        target.parent.mkdir(parents=True, exist_ok=True)
        with target.open("xb") as output:
            output.write(content)
    print(f"Hotovo. Nově zapsaných souborů: {len(pending)}. Instalátory nebyly spuštěny.")

BASE = Path.home() / '.local/share/cosmic-alt-tab-mru'
BIN = Path.home() / '.local/bin/cosmic-ext-app-switcher'
CONFIG = Path(os.environ.get('XDG_CONFIG_HOME', str(Path.home() / '.config')))
UNIT = CONFIG / 'systemd/user' / SERVICE
START = Path.home() / '.local/bin/cosmic-ext-app-switcher-mru-start'
AUTOSTART = CONFIG / 'autostart/cosmic-ext-app-switcher-mru.desktop'
PROJECT_DIR = Path(__file__).resolve().parent


def run(argv, **kwargs):
    return subprocess.run([str(x) for x in argv], check=True, **kwargs)


def status():
    return subprocess.run(['systemctl', '--user', 'is-active', '--quiet', SERVICE]).returncode == 0


def atomic_bytes(path, data, mode):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(prefix='.' + path.name + '.', dir=path.parent)
    try:
        with os.fdopen(fd, 'wb') as output:
            output.write(data)
            output.flush()
            os.fsync(output.fileno())
        os.chmod(tmp, mode)
        os.replace(tmp, path)
    finally:
        if os.path.lexists(tmp):
            os.unlink(tmp)


def backup(paths):
    folder = BASE / 'backups' / datetime.datetime.now().strftime('%Y%m%d-%H%M%S-%f')
    folder.mkdir(parents=True, mode=0o700)
    items = []
    for i, target in enumerate(paths):
        item = {'path': str(target), 'kind': 'missing'}
        if target.is_symlink():
            item.update(kind='symlink', link=os.readlink(target))
        elif target.is_file():
            name = str(i) + '.backup'
            shutil.copy2(target, folder / name)
            item.update(kind='file', file=name, mode=target.stat().st_mode & 0o777)
        elif target.exists():
            raise RuntimeError(f'Neocekavany typ cile: {target}')
        items.append(item)
    manifest = {'items': items, 'service_was_active': status()}
    (folder / 'manifest.json').write_text(json.dumps(manifest, indent=2), encoding='utf-8')
    return folder


def restore(folder):
    manifest = json.loads((folder / 'manifest.json').read_text(encoding='utf-8'))
    expected = {str(x) for x in [BIN, UNIT, START, AUTOSTART]}
    if {item['path'] for item in manifest['items']} != expected:
        raise RuntimeError('Zaloha neodpovida teto instalaci.')
    for item in manifest['items']:
        if item['kind'] == 'file' and not (folder / item['file']).is_file():
            raise RuntimeError('V zaloze chybi soubor; obnova nebyla zahajena.')
    subprocess.run(['systemctl', '--user', 'stop', SERVICE], check=False)
    for item in manifest['items']:
        target = Path(item['path'])
        if item['kind'] == 'file':
            atomic_bytes(target, (folder / item['file']).read_bytes(), item['mode'])
        elif item['kind'] == 'symlink':
            target.unlink(missing_ok=True)
            target.symlink_to(item['link'])
        else:
            target.unlink(missing_ok=True)
    run(['systemctl', '--user', 'daemon-reload'])
    if manifest['service_was_active']:
        run(['systemctl', '--user', 'start', SERVICE])
    print('Predchozi instalace byla obnovena.', flush=True)


def import_environment():
    names = [name for name in ['WAYLAND_DISPLAY', 'DISPLAY', 'XDG_CURRENT_DESKTOP', 'XDG_SESSION_TYPE'] if name in os.environ]
    if names:
        run(['systemctl', '--user', 'import-environment', *names])


def desktop_quote(value):
    value = value.replace('%', '%%')
    for character in ['\\', '"', '`', '$']:
        value = value.replace(character, '\\' + character)
    value = value.replace('\\', '\\\\')
    return '"' + value + '"'


def install(source_dir: Path):
    if os.geteuid() == 0:
        raise RuntimeError('Spust instalator jako svuj bezny uzivatel, BEZ sudo.')
    if not os.environ.get('WAYLAND_DISPLAY') or not os.environ.get('XDG_RUNTIME_DIR'):
        raise RuntimeError('Spust instalator v terminalu uvnitr prihlaseneho COSMIC.')
    if not (source_dir / 'Cargo.toml').is_file():
        raise RuntimeError(f'Ve slozce {source_dir} chybi Cargo.toml.')

    cargo = shutil.which('cargo')
    if not cargo and (Path.home() / '.cargo/bin/cargo').is_file():
        cargo = str(Path.home() / '.cargo/bin/cargo')
    if not cargo:
        raise RuntimeError('Chybi cargo/Rust.')

    env = os.environ.copy()
    env['PATH'] = str(Path(cargo).parent) + os.pathsep + env.get('PATH', '')
    env['CARGO_TARGET_DIR'] = str(Path.home() / '.cache/cosmic-alt-tab-mru/target')
    env.setdefault('CARGO_BUILD_JOBS', '4')

    print(f'1/3 Kompiluji ze slozky: {source_dir}', flush=True)
    run([cargo, 'build', '--locked', '--release', '--bin', 'cosmic-ext-app-switcher'], cwd=source_dir, env=env)
    new_binary = Path(env['CARGO_TARGET_DIR']) / 'release/cosmic-ext-app-switcher'
    run([new_binary, '--check-compat'])

    print('2/3 Vytvarim zalohu a instaluji prepinac.', flush=True)
    folder = backup([BIN, UNIT, START, AUTOSTART])
    try:
        subprocess.run(['systemctl', '--user', 'stop', SERVICE], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        atomic_bytes(BIN, new_binary.read_bytes(), 0o755)
        unit = '''[Unit]
Description=COSMIC Alt-Tab per-window MRU history
PartOf=graphical-session.target
After=graphical-session.target

[Service]
Type=simple
ExecStart="%h/.local/bin/cosmic-ext-app-switcher" --daemon
Restart=on-failure
RestartSec=2
UMask=0077
'''
        atomic_bytes(UNIT, unit.encode(), 0o644)
        starter = '''#!/bin/sh
set -eu
[ -n "${WAYLAND_DISPLAY:-}" ] || exit 0
systemctl --user import-environment WAYLAND_DISPLAY
[ -z "${DISPLAY:-}" ] || systemctl --user import-environment DISPLAY
systemctl --user restart cosmic-ext-app-switcher-mru.service
'''
        atomic_bytes(START, starter.encode(), 0o755)
        desktop = '[Desktop Entry]\nType=Application\nName=COSMIC Alt-Tab MRU history\nExec=' + desktop_quote(str(START)) + '\nTerminal=false\nOnlyShowIn=COSMIC;\n'
        atomic_bytes(AUTOSTART, desktop.encode(), 0o644)
        run(['systemctl', '--user', 'daemon-reload'])
        import_environment()
        run(['systemctl', '--user', 'start', SERVICE])

        print('3/3 Kontroluji spojeni s MRU sluzbou.', flush=True)

                break

                raise RuntimeError('Sluzba se nespustila; obnovuji puvodni instalaci.')
            time.sleep(0.2)
        atomic_bytes(BASE / 'last-backup', (str(folder) + '\n').encode(), 0o600)
    except BaseException:
        restore(folder)
        raise

    print('\nHOTOVO. Prepinac je nainstalovany a sluzba bezi.')

pub fn runtime_dir() -> Result<std::path::PathBuf> {
    let path = std::env::var_os("XDG_RUNTIME_DIR")
        .map(std::path::PathBuf::from)
        .ok_or_else(|| {
            anyhow::anyhow!("Run inside your logged-in COSMIC desktop (XDG_RUNTIME_DIR is missing)")
        })?;
    Ok(path)
}

pub fn file_lock(name: &str, nonblocking: bool) -> Result<std::fs::File> {
    let file = std::fs::OpenOptions::new()
        .create(true)
        .truncate(false)
        .read(true)
        .write(true)
        .mode(0o600)
        .open(runtime_dir()?.join(name))?;
    let operation = libc::LOCK_EX | if nonblocking { libc::LOCK_NB } else { 0 };
    if unsafe { libc::flock(file.as_raw_fd(), operation) } != 0 {
        return Err(std::io::Error::last_os_error().into());
    }
    Ok(file)
}

        println!(

        );
        return Ok(());
    }
    if args.check_compat {
        return check_compat();
    }

    let startup_lock = file_lock("cosmic-ext-app-switcher-ui.lock", false)?;

        b"prev" as &[u8]
    } else {
        b"next" as &[u8]

        stream.set_write_timeout(Some(std::time::Duration::from_secs(1)))?;
        stream.write_all(cmd)?;
        return Ok(());

    drop(startup_lock);
    if snapshot.toplevels.is_empty() {
        return Ok(());
    }
    let res = app::run(
        snapshot.toplevels,
        args.reverse,
        snapshot.generation,
        load_theme(),
    );
    let _ = std::fs::remove_file(socket_path());
    res
}

mod mru {
    use std::{cmp::Reverse, collections::HashMap};

    #[derive(Default)]
    pub struct History {
        clock: u64,
        windows: HashMap<u64, (bool, u64)>,
    }

    impl History {
        pub fn open(&mut self, id: u64) {
            self.windows.entry(id).or_insert((false, 0));
        }
        pub fn close(&mut self, id: u64) {
            self.windows.remove(&id);
        }
        pub fn state(&mut self, id: u64, activated: bool) {
            let Some((was_active, last_used)) = self.windows.get_mut(&id) else {
                return;
            };
            if activated && !*was_active {
                self.clock += 1;
                *last_used = self.clock;
            }
            *was_active = activated;
        }
        pub fn sort_key(&self, id: u64) -> (Reverse<u64>, u64) {
            (
                Reverse(self.windows.get(&id).map(|w| w.1).unwrap_or(0)),
                id,
            )
        }
    }
}

mod icons {
    use cosmic::widget::icon;
    use freedesktop_desktop_entry::{DesktopEntry, Iter as DesktopIter};
    use std::collections::HashSet;
    use std::path::{Path, PathBuf};

    const FALLBACK_ICON: &str = "application-x-executable";

    pub enum AppIcon {
        Named(String),
        File(PathBuf),
    }

    pub struct AppVisual {
        pub icon: AppIcon,
        pub label: String,
    }

    pub fn visual_for(app_id: &str, window_title: &str, size: u16) -> AppVisual {
        if app_id.starts_with("steam_app_") {
            return AppVisual {
                icon: resolve("steam", size),
                label: first_non_empty(&[window_title, "Steam"]).to_string(),
            };
        }

        let entry = desktop_entry_for(app_id);
        let label = entry
            .as_ref()
            .and_then(|e| e.name.as_deref())
            .filter(|n| !n.is_empty())
            .unwrap_or_else(|| first_non_empty(&[window_title, app_id, "Unknown"]))
            .to_string();

        let icon = match entry.and_then(|e| e.icon) {
            Some(field) if Path::new(&field).is_absolute() && Path::new(&field).is_file() => {
                AppIcon::File(PathBuf::from(field))
            }
            Some(field) => resolve(&icon_name_from_field(&field), size),
            None => resolve(app_id.split('.').next_back().unwrap_or(app_id), size),
        };

        AppVisual { icon, label }
    }

    fn first_non_empty<'a>(candidates: &[&'a str]) -> &'a str {
        candidates
            .iter()
            .copied()
            .find(|c| !c.is_empty())
            .unwrap_or_default()
    }

    fn resolve(name: &str, size: u16) -> AppIcon {
        if icon::from_name(name).size(size).path().is_some() {
            return AppIcon::Named(name.to_string());
        }
        AppIcon::Named(FALLBACK_ICON.to_string())
    }

    struct DesktopInfo {
        icon: Option<String>,
        name: Option<String>,
    }

    fn desktop_entry_for(app_id: &str) -> Option<DesktopInfo> {
        if app_id.is_empty() {
            return None;
        }
        let dirs = search_dirs();

        for dir in &dirs {
            if let Some(info) = read_entry(&dir.join(format!("{app_id}.desktop"))) {
                return Some(info);
            }
        }

        for path in DesktopIter::new(dirs.clone()) {
            let Ok(bytes) = std::fs::read(&path) else { continue };
            let Ok(s) = std::str::from_utf8(&bytes) else { continue };
            let Ok(entry) = DesktopEntry::decode(&path, s) else { continue };
            let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or_default();
            let claims = entry
                .startup_wm_class()
                .is_some_and(|c| c.eq_ignore_ascii_case(app_id))
                || stem_matches(stem, app_id);
            if claims {
                return Some(DesktopInfo {
                    icon: entry.icon().map(ToString::to_string),
                    name: entry.name(None).map(|n| n.to_string()),
                });
            }
        }
        None
    }

    fn stem_matches(stem: &str, app_id: &str) -> bool {
        stem.eq_ignore_ascii_case(app_id)
            || stem
                .rsplit('.')
                .next()
                .is_some_and(|last| last.eq_ignore_ascii_case(app_id))
    }

    fn read_entry(path: &Path) -> Option<DesktopInfo> {
        let bytes = std::fs::read(path).ok()?;
        let s = std::str::from_utf8(&bytes).ok()?;
        let entry = DesktopEntry::decode(path, s).ok()?;
        Some(DesktopInfo {
            icon: entry.icon().map(ToString::to_string),
            name: entry.name(None).map(|n| n.to_string()),
        })
    }

    fn search_dirs() -> Vec<PathBuf> {
        let home = std::env::var("HOME").unwrap_or_default();
        let data_home = std::env::var("XDG_DATA_HOME")
            .ok()
            .filter(|d| !d.is_empty())
            .unwrap_or_else(|| format!("{home}/.local/share"));
        let data_dirs = std::env::var("XDG_DATA_DIRS")
            .ok()
            .filter(|d| !d.is_empty())
            .unwrap_or_else(|| "/usr/local/share:/usr/share".to_string());

        let xdg = std::iter::once(data_home.clone())
            .chain(data_dirs.split(':').map(ToString::to_string))
            .filter(|d| !d.is_empty())
            .map(|d| PathBuf::from(d).join("applications"));

        let extra = [
            PathBuf::from("/var/lib/flatpak/exports/share/applications"),
            PathBuf::from(format!("{data_home}/flatpak/exports/share/applications")),
            PathBuf::from("/var/lib/snapd/desktop/applications"),
        ];

        let mut seen = HashSet::new();
        xdg.chain(extra).filter(|d| seen.insert(d.clone())).collect()
    }

    fn icon_name_from_field(icon: &str) -> String {
        if icon.starts_with('/') {
            Path::new(icon)
                .file_stem()
                .and_then(|s| s.to_str())
                .unwrap_or(icon)
                .to_string()
        } else {
            icon.to_string()
        }
    }
}

mod app {
    use anyhow::Result;
    use cosmic::{
        app::{Application, Core, Settings, Task},
        iced::{
            self, event,
            keyboard::{self, key::Named},
            platform_specific::{
                runtime::wayland::layer_surface::SctkLayerSurfaceSettings,
                shell::wayland::commands::layer_surface::{
                    destroy_layer_surface, get_layer_surface, Anchor, KeyboardInteractivity, Layer,
                },
            },
            window::Id as WindowId,
            Event, Subscription,
        },
        Element,
    };
    use std::time::Duration;
    use switcher_config::{Theme, ThemeValues};

    use crate::icons::{visual_for, AppVisual};
    use crate::wayland::ToplevelEntry;

    pub struct AppSwitcher {
        core: Core,
        pub toplevels: Vec<ToplevelEntry>,
        pub visuals: Vec<AppVisual>,
        pub selected: usize,
        generation: String,
        pub finishing: bool,
        pub ready: bool,
        super_held: bool,
        alt_held: bool,
        surface_id: WindowId,
        pub theme: ThemeValues,
    }

    #[derive(Debug, Clone)]
    pub enum Message {
        SelectNext,
        SelectPrev,
        SelectIndex(usize),
        Activate,
        Cancel,
        Ready,
        KeyEvent(keyboard::Event),
    }

    impl Application for AppSwitcher {
        type Executor = cosmic::executor::Default;
        type Flags = (Vec<ToplevelEntry>, bool, String, Theme);
        type Message = Message;

        const APP_ID: &'static str = "io.github.cosmic-ext-app-switcher";

        fn core(&self) -> &Core {
            &self.core
        }
        fn core_mut(&mut self) -> &mut Core {
            &mut self.core
        }

        fn init(core: Core, flags: Self::Flags) -> (Self, Task<Message>) {
            let (toplevels, reverse, generation, theme_preset) = flags;
            let n = toplevels.len();
            let selected = if reverse {
                n.saturating_sub(1)
            } else {
                1.min(n.saturating_sub(1))
            };

            let theme = theme_preset.values();
            let visuals: Vec<AppVisual> = toplevels
                .iter()
                .map(|entry| visual_for(&entry.app_id, &entry.title, theme.icon_size))
                .collect();

            let (surface_w, surface_h) = crate::ui::surface_size(toplevels.len(), &theme);

            let surface_id = WindowId::unique();
            let layer_task = get_layer_surface::<cosmic::Action<Message>>(SctkLayerSurfaceSettings {
                id: surface_id,
                layer: Layer::Overlay,
                keyboard_interactivity: KeyboardInteractivity::Exclusive,
                anchor: Anchor::empty(),
                size: Some((Some(surface_w), Some(surface_h))),
                ..Default::default()
            });

            let ready_task = Task::perform(
                async {
                    tokio::time::sleep(Duration::from_millis(28)).await;
                },
                |_| cosmic::Action::App(Message::Ready),
            );

            (
                AppSwitcher {
                    core,
                    toplevels,
                    visuals,
                    selected,
                    generation,
                    finishing: false,
                    ready: false,
                    super_held: false,
                    alt_held: true,
                    surface_id,
                    theme,
                },
                Task::batch([layer_task, ready_task]),
            )
        }

        fn update(&mut self, msg: Message) -> Task<Message> {
            if self.finishing {
                return Task::none();
            }
            let n = self.toplevels.len();
            if n == 0 {
                return iced::exit();
            }
            match msg {
                Message::Ready => {
                    self.ready = true;
                }
                Message::SelectNext => {
                    self.selected = (self.selected + 1) % n;
                }
                Message::SelectPrev => {
                    self.selected = (self.selected + n - 1) % n;
                }
                Message::SelectIndex(i) => {
                    if i < n {
                        self.selected = i;
                    }
                }
                Message::Activate => {
                    self.finishing = true;
                    self.ready = false;
                    let _ = std::fs::remove_file(crate::socket_path());
                    if let Err(error) = crate::wayland::activate(
                        &self.generation,
                        self.toplevels[self.selected].handle_key,
                    ) {
                        log::error!("Could not activate selected window: {error:#}");
                    }
                    return Task::batch([destroy_layer_surface(self.surface_id), iced::exit()]);
                }
                Message::Cancel => {
                    self.finishing = true;
                    self.ready = false;
                    let _ = std::fs::remove_file(crate::socket_path());
                    return Task::batch([destroy_layer_surface(self.surface_id), iced::exit()]);
                }
                Message::KeyEvent(ke) => match ke {
                    keyboard::Event::KeyPressed { key, modifiers, .. } => match key {
                        iced::keyboard::Key::Named(Named::Tab) => {
                            return self.update(if modifiers.shift() {
                                Message::SelectPrev
                            } else {
                                Message::SelectNext
                            });
                        }
                        iced::keyboard::Key::Named(Named::ArrowRight)
                        | iced::keyboard::Key::Named(Named::ArrowDown) => {
                            return self.update(Message::SelectNext);
                        }
                        iced::keyboard::Key::Named(Named::ArrowLeft)
                        | iced::keyboard::Key::Named(Named::ArrowUp) => {
                            return self.update(Message::SelectPrev);
                        }
                        iced::keyboard::Key::Named(Named::Escape) => {
                            return self.update(Message::Cancel);
                        }
                        iced::keyboard::Key::Named(Named::Enter) => {
                            return self.update(Message::Activate);
                        }
                        _ => {}
                    },
                    keyboard::Event::KeyReleased { key, .. } => match key {
                        iced::keyboard::Key::Named(Named::Alt)
                        | iced::keyboard::Key::Named(Named::AltGraph)
                        | iced::keyboard::Key::Named(Named::Super) => {
                            return self.update(Message::Activate);
                        }
                        _ => {}
                    },
                    keyboard::Event::ModifiersChanged(mods) => {
                        if !mods.alt() && !mods.logo() {
                            return self.update(Message::Activate);
                        }
                        self.super_held = mods.logo();
                        self.alt_held = mods.alt();
                    }
                },
            }
            Task::none()
        }

        fn subscription(&self) -> Subscription<Message> {
            let key_sub = event::listen_with(|event, _status, _window| match event {
                Event::Keyboard(ke) => Some(Message::KeyEvent(ke)),
                Event::Window(iced::window::Event::Unfocused) => Some(Message::Cancel),
                _ => None,
            });

            let socket_sub = {
                use cosmic::iced::futures::SinkExt;
                use std::any::TypeId;
                struct SocketSub;
                Subscription::run_with(TypeId::of::<SocketSub>(), |_| {
                    cosmic::iced::stream::channel(
                        16,
                        |mut tx: cosmic::iced::futures::channel::mpsc::Sender<Message>| async move {
                            use tokio::io::AsyncReadExt;
                            let listener = tokio::net::UnixListener::from_std(
                                crate::UI_LISTENER
                                    .get()
                                    .expect("UI socket initialized")
                                    .try_clone()
                                    .expect("clone UI socket"),
                            )
                            .expect("nonblocking UI socket");
                            loop {
                                if let Ok((mut stream, _)) = listener.accept().await {
                                    let mut buf = Vec::new();
                                    let read = tokio::time::timeout(
                                        std::time::Duration::from_secs(1),
                                        (&mut stream).take(16).read_to_end(&mut buf),
                                    )
                                    .await;
                                    if !matches!(read, Ok(Ok(_))) {
                                        continue;
                                    }
                                    let msg = match buf.as_slice() {
                                        b"next" => Message::SelectNext,
                                        b"prev" => Message::SelectPrev,
                                        _ => continue,
                                    };
                                    let _ = tx.send(msg).await;
                                }
                            }
                        },
                    )
                })
            };

            Subscription::batch([key_sub, socket_sub])
        }

        fn view(&self) -> Element<'_, Message> {
            crate::ui::view(self)
        }

        fn view_window(&self, _id: WindowId) -> Element<'_, Message> {
            crate::ui::view(self)
        }
    }

    pub fn run(
        toplevels: Vec<ToplevelEntry>,
        reverse: bool,
        generation: String,
        theme: Theme,
    ) -> Result<()> {
        let settings = Settings::default().no_main_window(true).transparent(true);
        cosmic::app::run::<AppSwitcher>(settings, (toplevels, reverse, generation, theme))
            .map_err(|e| anyhow::anyhow!("{e:?}"))
    }
}

mod ui {
    use cosmic::{
        iced::{
            widget::container::Style as ContainerStyle, Alignment, Background, Border, Color,
            Length, Shadow, Vector,
        },
        widget::{column, container, icon, mouse_area, row, text, Space},
        Element,
    };
    use switcher_config::ThemeValues;

    use crate::app::{AppSwitcher, Message};
    use crate::icons::AppIcon;

    const CELL_PAD: u16 = 10;
    const CELL_SPACING: u16 = 4;
    const STRIP_PAD_X: u16 = 18;
    const STRIP_PAD_Y: u16 = 14;
    const TITLE_SIZE: u16 = 14;
    const TITLE_HEIGHT: u16 = 20;
    const TITLE_GAP: u16 = 6;
    const SURFACE_MARGIN: u32 = 40;

    pub fn surface_size(window_count: usize, theme: &ThemeValues) -> (u32, u32) {
        let n = window_count as u32;
        let cell = u32::from(theme.icon_size) + 2 * u32::from(CELL_PAD);
        let strip_w =
            n * cell + n.saturating_sub(1) * u32::from(CELL_SPACING) + 2 * u32::from(STRIP_PAD_X);
        let strip_h = cell
            + u32::from(TITLE_GAP)
            + u32::from(TITLE_HEIGHT)
            + 2 * u32::from(STRIP_PAD_Y);
        (strip_w + SURFACE_MARGIN, strip_h + SURFACE_MARGIN)
    }

    fn fit_title(title: &str, surface_w: u32) -> String {
        let usable = surface_w
            .saturating_sub(SURFACE_MARGIN)
            .saturating_sub(2 * u32::from(STRIP_PAD_X));
        let max_chars = (usable / (u32::from(TITLE_SIZE) * 55 / 100)).max(3) as usize;
        if title.chars().count() <= max_chars {
            return title.to_string();
        }
        let kept: String = title.chars().take(max_chars.saturating_sub(1)).collect();
        format!("{}…", kept.trim_end())
    }

    pub fn view(state: &AppSwitcher) -> Element<'_, Message> {
        let tv = &state.theme;
        let (surface_w, surface_h) = surface_size(state.toplevels.len(), tv);

        if !state.ready || state.finishing {
            return container(Space::new())
                .width(Length::Fixed(surface_w as f32))
                .height(Length::Fixed(surface_h as f32))
                .into();
        }

        let bg = Color::from_rgba(tv.bg[0], tv.bg[1], tv.bg[2], tv.bg[3]);
        let sel_bg = Color::from_rgba(
            tv.selected_bg[0],
            tv.selected_bg[1],
            tv.selected_bg[2],
            tv.selected_bg[3],
        );
        let corner = tv.corner_radius;
        let icon_sz = tv.icon_size;
        let cell_px = f32::from(icon_sz + 2 * CELL_PAD);

        let mut selected_label = String::new();

        let cells: Vec<Element<Message>> = state
            .visuals
            .iter()
            .enumerate()
            .map(|(i, visual)| {
                let selected = i == state.selected;
                if selected {
                    selected_label = visual.label.clone();
                }

                let app_icon: Element<Message> = match &visual.icon {
                    AppIcon::Named(name) => icon::from_name(name.as_str())
                        .size(icon_sz)
                        .icon()
                        .size(icon_sz)
                        .width(Length::Fixed(f32::from(icon_sz)))
                        .height(Length::Fixed(f32::from(icon_sz)))
                        .into(),
                    AppIcon::File(path) => icon::icon(icon::from_path(path.clone()))
                        .size(icon_sz)
                        .width(Length::Fixed(f32::from(icon_sz)))
                        .height(Length::Fixed(f32::from(icon_sz)))
                        .into(),
                };

                let cell = container(app_icon)
                    .width(Length::Fixed(cell_px))
                    .height(Length::Fixed(cell_px))
                    .center_x(Length::Fixed(cell_px))
                    .center_y(Length::Fixed(cell_px))
                    .padding(CELL_PAD)
                    .style(move |_: &cosmic::Theme| {
                        if selected {
                            ContainerStyle {
                                background: Some(Background::Color(sel_bg)),
                                border: Border {
                                    radius: (corner - 2.0).into(),
                                    width: 0.0,
                                    color: Color::TRANSPARENT,
                                },
                                ..Default::default()
                            }
                        } else {
                            ContainerStyle::default()
                        }
                    });

                mouse_area(cell)
                    .on_press(Message::SelectIndex(i))
                    .on_release(Message::Activate)
                    .into()
            })
            .collect();

        let fg = Color::from_rgba(tv.fg[0], tv.fg[1], tv.fg[2], tv.fg[3]);
        let title = text(fit_title(&selected_label, surface_w))
            .size(TITLE_SIZE)
            .height(TITLE_HEIGHT)
            .class(cosmic::theme::Text::Color(fg));

        let strip_w = surface_w.saturating_sub(SURFACE_MARGIN) as f32;
        let strip_h = surface_h.saturating_sub(SURFACE_MARGIN) as f32;

        let strip = container(
            column![
                row(cells).spacing(CELL_SPACING).align_y(Alignment::Center),
                title,
            ]
            .spacing(TITLE_GAP)
            .align_x(Alignment::Center),
        )
        .width(Length::Fixed(strip_w))
        .height(Length::Fixed(strip_h))
        .style(move |_: &cosmic::Theme| ContainerStyle {
            background: Some(Background::Color(bg)),
            border: Border {
                radius: corner.into(),
                width: 0.0,
                color: Color::TRANSPARENT,
            },
            shadow: Shadow {
                color: Color {
                    r: 0.0,
                    g: 0.0,
                    b: 0.0,
                    a: 0.6,
                },
                offset: Vector::new(0.0, 8.0),
                blur_radius: 32.0,
            },
            ..Default::default()
        })
        .padding([STRIP_PAD_Y, STRIP_PAD_X]);

        container(strip)
            .width(Length::Fixed(surface_w as f32))
            .height(Length::Fixed(surface_h as f32))
            .center_x(Length::Fixed(surface_w as f32))
            .center_y(Length::Fixed(surface_h as f32))
            .into()
    }
}

        },
    };

    #[derive(Debug, Clone, Serialize, Deserialize)]
    pub struct ToplevelEntry {
        pub app_id: String,
        pub title: String,
        pub is_active: bool,
        pub handle_key: u64,
    }

    #[derive(Serialize, Deserialize)]
    pub struct Snapshot {
        pub generation: String,
        pub toplevels: Vec<ToplevelEntry>,
    }

    #[derive(Serialize, Deserialize)]
    enum Request {
        List(WorkspaceScope),
        Activate { generation: String, key: u64 },
        Ping,
    }

    #[derive(Serialize, Deserialize)]
    enum Response {
        List(Snapshot),
        Ok,
        Error(String),
    }

    pub fn daemon_socket_path() -> Result<std::path::PathBuf> {
        Ok(crate::runtime_dir()?.join("cosmic-ext-app-switcher-mru.sock"))
    }

    fn request(request: &Request) -> Result<Response> {
        let mut stream = UnixStream::connect(daemon_socket_path()?).context(
            "MRU service is not running. Run: systemctl --user restart cosmic-ext-app-switcher-mru.service",
        )?;
        stream.set_read_timeout(Some(Duration::from_secs(2)))?;
        stream.set_write_timeout(Some(Duration::from_secs(2)))?;
        serde_json::to_writer(&mut stream, request)?;
        stream.shutdown(std::net::Shutdown::Write)?;
        let mut bytes = Vec::new();
        stream.take(4 * 1024 * 1024).read_to_end(&mut bytes)?;
        let reply: Response = serde_json::from_slice(&bytes)?;
        if let Response::Error(message) = &reply {
            return Err(anyhow!("{message}"));
        }
        Ok(reply)
    }

    pub fn snapshot(scope: WorkspaceScope) -> Result<Snapshot> {
        match request(&Request::List(scope))? {
            Response::List(snapshot) => Ok(snapshot),
            _ => Err(anyhow!("Unexpected MRU service response")),
        }
    }

    pub fn activate(generation: &str, key: u64) -> Result<()> {
        match request(&Request::Activate {
            generation: generation.into(),
            key,
        })? {
            Response::Ok => Ok(()),
            _ => Err(anyhow!("Unexpected MRU activation response")),
        }
    }

    pub fn ping() -> Result<()> {
        match request(&Request::Ping)? {
            Response::Ok => Ok(()),
            _ => Err(anyhow!("Unexpected MRU health response")),
        }
    }

    const TOPLEVEL_INFO_VERSION: u32 = 1;
    const TOPLEVEL_MANAGER_VERSION: u32 = 1;
    const SEAT_VERSION: u32 = 7;

    const REQUIRED_GLOBALS: &[(&str, u32)] = &[
        ("zcosmic_toplevel_info_v1", TOPLEVEL_INFO_VERSION),
        ("zcosmic_toplevel_manager_v1", TOPLEVEL_MANAGER_VERSION),
        ("zwlr_layer_shell_v1", 1),
        ("wl_seat", SEAT_VERSION),
    ];

    pub struct GlobalStatus {
        interface: &'static str,
        needed: u32,
        advertised: Option<u32>,
    }

    impl GlobalStatus {
        pub fn ok(&self) -> bool {
            self.advertised.is_some_and(|v| v >= self.needed)
        }
    }

    impl std::fmt::Display for GlobalStatus {
        fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
            let (interface, needed) = (self.interface, self.needed);
            match self.advertised {
                Some(v) if v >= needed => write!(f, "{interface}: ok (v{v}, needs v{needed})"),
                Some(v) => write!(f, "{interface}: TOO OLD (v{v}, needs v{needed})"),
                None => write!(f, "{interface}: NOT offered (needs v{needed})"),
            }
        }
    }

    fn required_globals_status(advertised: &[(String, u32)]) -> Vec<GlobalStatus> {
        REQUIRED_GLOBALS
            .iter()
            .map(|&(interface, needed)| GlobalStatus {
                interface,
                needed,
                advertised: advertised
                    .iter()
                    .filter(|(i, _)| i == interface)
                    .map(|&(_, v)| v)
                    .max(),
            })
            .collect()
    }

    pub fn probe_required_globals() -> Result<Vec<GlobalStatus>> {
        let conn = Connection::connect_to_env()
            .context("could not connect to the Wayland compositor (is COSMIC running?)")?;
        let (globals, _queue) = registry_queue_init::<RegistryProbe>(&conn)?;
        let advertised: Vec<(String, u32)> = globals
            .contents()
            .clone_list()
            .into_iter()
            .map(|g| (g.interface, g.version))
            .collect();
        Ok(required_globals_status(&advertised))
    }

    struct AppData {
        history: History,
        next_key: u64,
        generation: String,
        toplevels: Vec<Toplevel>,
        _info: Option<ZcosmicToplevelInfoV1>,
        manager: Option<ZcosmicToplevelManagerV1>,
        seat: Option<wl_seat::WlSeat>,
        _workspace_manager: Option<ZcosmicWorkspaceManagerV1>,
        outputs: Vec<wl_output::WlOutput>,
        toplevel_info_name: Option<u32>,
        globals: Vec<(String, u32)>,
    }

    struct Toplevel {
        key: u64,
        handle: ZcosmicToplevelHandleV1,
        app_id: String,
        title: String,
        is_active: bool,
        outputs: Vec<wl_output::WlOutput>,
        workspaces: Vec<ZcosmicWorkspaceHandleV1>,
    }

    pub fn run_daemon() -> Result<()> {
        let _lock = crate::file_lock("cosmic-ext-app-switcher-mru.lock", true)?;
        let conn = Connection::connect_to_env()?;
        let display = conn.display();
        let mut queue = conn.new_event_queue();
        let qh = queue.handle();

        let registry = display.get_registry(&qh, ());

        let mut data = AppData {
            history: History::default(),
            next_key: 0,
            generation: format!(
                "{}-{}",
                std::process::id(),
                SystemTime::now().duration_since(UNIX_EPOCH)?.as_nanos()
            ),
            toplevels: vec![],
            _info: None,
            manager: None,
            seat: None,
            _workspace_manager: None,
            outputs: vec![],
            toplevel_info_name: None,
            globals: vec![],
        };

        queue.roundtrip(&mut data)?;

        let missing: Vec<String> = required_globals_status(&data.globals)
            .iter()
            .filter(|s| !s.ok())
            .map(ToString::to_string)
            .collect();
        if !missing.is_empty() {
            return Err(anyhow!(
                "cosmic-ext-app-switcher can't run: missing Wayland interfaces ({}).",
                missing.join("; "),
            ));
        }

        queue.roundtrip(&mut data)?;

        if let Some(name) = data.toplevel_info_name.take() {
            data._info = Some(registry.bind::<ZcosmicToplevelInfoV1, _, _>(
                name,
                TOPLEVEL_INFO_VERSION,
                &qh,
                (),
            ));
        }

        for _ in 0..5 {
            queue.roundtrip(&mut data)?;
        }

        let path = daemon_socket_path()?;
        let _ = std::fs::remove_file(&path);
        let listener = UnixListener::bind(&path)?;
        std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600))?;
        listener.set_nonblocking(true)?;
        let _cleanup = crate::SocketCleanup(path);
        log::info!("MRU service ready; history starts now");

        loop {
            queue.dispatch_pending(&mut data)?;
            conn.flush()?;
            let Some(guard) = queue.prepare_read() else {
                continue;
            };
            let mut fds = [
                libc::pollfd {
                    fd: conn.backend().poll_fd().as_raw_fd(),
                    events: libc::POLLIN,
                    revents: 0,
                },
                libc::pollfd {
                    fd: listener.as_raw_fd(),
                    events: libc::POLLIN,
                    revents: 0,
                },
            ];
            let ready = unsafe { libc::poll(fds.as_mut_ptr(), fds.len() as libc::nfds_t, -1) };
            if ready < 0 {
                drop(guard);
                let error = std::io::Error::last_os_error();
                if error.kind() == std::io::ErrorKind::Interrupted {
                    continue;
                }
                return Err(error.into());
            }
            if fds[0].revents != 0 {
                guard.read()?;
                queue.dispatch_pending(&mut data)?;
            } else {
                drop(guard);
            }
            if fds[1].revents & libc::POLLIN != 0 {
                let (mut stream, _) = listener.accept()?;
                stream.set_read_timeout(Some(Duration::from_millis(500)))?;
                stream.set_write_timeout(Some(Duration::from_millis(500)))?;
                let mut bytes = Vec::new();
                if (&mut stream).take(65536).read_to_end(&mut bytes).is_err() {
                    continue;
                }
                let reply = match serde_json::from_slice::<Request>(&bytes) {
                    Ok(Request::List(scope)) => {
                        queue.roundtrip(&mut data)?;
                        Response::List(data.snapshot(scope))
                    }
                    Ok(Request::Activate { generation, key }) => {
                        queue.roundtrip(&mut data)?;
                        if generation != data.generation {
                            Response::Error("MRU service restarted; reopen Alt+Tab".into())
                        } else if let Some(t) = data.toplevels.iter().find(|t| t.key == key) {
                            if let (Some(manager), Some(seat)) = (&data.manager, &data.seat) {
                                manager.activate(&t.handle, seat);
                                queue.roundtrip(&mut data)?;
                                Response::Ok
                            } else {
                                Response::Error("Activation protocol unavailable".into())
                            }
                        } else {
                            Response::Error("Selected window has already closed".into())
                        }
                    }
                    Ok(Request::Ping) => Response::Ok,
                    Err(error) => Response::Error(error.to_string()),
                };
                let _ = serde_json::to_writer(&mut stream, &reply);
                let _ = stream.flush();
            }
        }
    }

    impl AppData {
        fn snapshot(&self, scope: WorkspaceScope) -> Snapshot {
            let reference = self
                .toplevels
                .iter()
                .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
                .min_by_key(|t| self.history.sort_key(t.key));
            let active_outputs = reference.map(|t| t.outputs.as_slice()).unwrap_or(&[]);
            let mut entries: Vec<_> = self
                .toplevels
                .iter()
                .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
                .filter(|t| match scope {
                    WorkspaceScope::AllWorkspaces => true,
                    WorkspaceScope::CurrentWorkspace => true,
                    WorkspaceScope::CurrentOutput => {
                        active_outputs.is_empty()
                            || t.outputs.iter().any(|o| active_outputs.contains(o))
                    }
                })
                .map(|t| ToplevelEntry {
                    app_id: t.app_id.clone(),
                    title: t.title.clone(),
                    is_active: t.is_active,
                    handle_key: t.key,
                })
                .collect();
            entries.sort_by_key(|t| self.history.sort_key(t.handle_key));
            Snapshot {
                generation: self.generation.clone(),
                toplevels: entries,
            }
        }
    }

    impl Dispatch<wl_registry::WlRegistry, ()> for AppData {
        fn event(
            data: &mut Self,
            registry: &wl_registry::WlRegistry,
            event: wl_registry::Event,
            _: &(),
            _: &Connection,
            qh: &QueueHandle<Self>,
        ) {
            if let wl_registry::Event::Global {
                name,
                interface,
                version,
            } = event
            {
                data.globals.push((interface.clone(), version));
                match interface.as_str() {
                    "zcosmic_toplevel_info_v1" if version >= TOPLEVEL_INFO_VERSION => {
                        data.toplevel_info_name = Some(name);
                    }
                    "zcosmic_toplevel_manager_v1" if version >= TOPLEVEL_MANAGER_VERSION => {
                        data.manager = Some(registry.bind::<ZcosmicToplevelManagerV1, _, _>(
                            name,
                            TOPLEVEL_MANAGER_VERSION,
                            qh,
                            (),
                        ));
                    }
                    "wl_seat" if version >= SEAT_VERSION => {
                        if data.seat.is_none() {
                            data.seat =

# Návod a oprava: COSMIC App Switcher (`Alt + Tab` se šipkami)

Tento dokument popisuje princip fungování přepínače oken **`cosmic-ext-app-switcher`** v prostředí COSMIC (Pop!_OS) a obsahuje kompletní skript pro jeho instalaci a úpravu tak, aby:
1. Šlo v otevřeném přepínači listovat pomocí **šipek na klávesnici** (`Doleva`, `Doprava`, `Nahoru`, `Dolů`) během držení klávesy `Alt`.
2. Okno přepínače **spolehlivě zmizelo a aktivovalo vybranou aplikaci** okamžitě po puštění klávesy `Alt` (nebo `Super`).

---

## 1. Jak ten přepínač vlastně funguje?

Přepínač `cosmic-ext-app-switcher` není běžná aplikace, která by neustále běžela na pozadí a spotřebovávala RAM. Funguje na principu **Wayland Layer Shell** a **Unix socketu**:

1. **První stisk `Alt + Tab`:** Systémová zkratka v COSMIC zavolá binárku `~/.local/bin/cosmic-ext-app-switcher`. Ta si přes Wayland protokol (`ext-foreign-toplevel-list` a `cosmic-toplevel-info`) vyžádá seznam otevřených oken a vykreslí na obrazovku překryvnou lištu (`Layer::Overlay`).
2. **Exkluzivní klávesnice (`KeyboardInteractivity::Exclusive`):** Jakmile se lišta vykreslí, vezme si veškerý vstup z klávesnice pro sebe. Díky tomu může přímo číst stisky kláves `Tab`, `Escape`, `Enter` a nově i **šipek**.
3. **Unix Socket (pro další stisky):** Současně aplikace vytvoří dočasný socket. Pokud by další stisk zkratky zavolal binárku znovu, druhá instance se neotevře – pouze pošle prvnímu oknu přes socket zprávu `"next"` nebo `"prev"` a okamžitě se ukončí.
4. **Proč v původní verzi okno občas nezavřelo po puštění `Alt`?**
   * Původní kód nastavoval při startu proměnnou `alt_held: false` a čekal na změnu modifikátorů (`ModifiersChanged`).
   * Když jsi stiskl `Alt + Tab` a hned pustil (než se okno stihlo na Waylandu vykreslit), nebo když jsi držel `Alt` a mačkal šipky, událost pro uvolnění se špatně vyhodnotila a lišta zůstala viset na obrazovce.
   * **Naše oprava:** Nastavuje `alt_held: true` hned při inicializaci, hlídá přímé uvolnění fyzických kláves (`KeyReleased` pro `Alt`, `AltGraph` a `Super`) a zároveň kontroluje stav modifikátorů (`!mods.alt() && !mods.logo()`).

pub fn file_lock(name: &str, nonblocking: bool) -> Result<std::fs::File> {
    let file = std::fs::OpenOptions::new()
        .create(true)
        .truncate(false)
        .read(true)
        .write(true)
        .mode(0o600)
        .open(runtime_dir()?.join(name))?;
    let operation = libc::LOCK_EX | if nonblocking { libc::LOCK_NB } else { 0 };
    if unsafe { libc::flock(file.as_raw_fd(), operation) } != 0 {
        return Err(std::io::Error::last_os_error().into());
    }
    Ok(file)
}

        return Ok(());
    }
    let res = app::run(snapshot.toplevels, args.reverse, snapshot.generation, load_theme());
    let _ = std::fs::remove_file(socket_path());
    res
}

pub struct AppSwitcher {
    core:          Core,
    pub toplevels: Vec<ToplevelEntry>,
    pub visuals:   Vec<AppVisual>,
    pub selected:  usize,
    generation:    String,
    pub finishing: bool,
    pub ready:     bool,
    super_held:    bool,
    alt_held:      bool,
    surface_id:    WindowId,
    pub theme:     ThemeValues,
}

#[derive(Debug, Clone)]
pub enum Message {
    SelectNext,
    SelectPrev,
    SelectIndex(usize),
    Activate,
    Cancel,
    Ready,
    KeyEvent(keyboard::Event),
}

impl Application for AppSwitcher {
    type Executor = cosmic::executor::Default;
    type Flags    = (Vec<ToplevelEntry>, bool, String, Theme);
    type Message  = Message;

    const APP_ID: &'static str = "io.github.cosmic-ext-app-switcher";

    fn core(&self) -> &Core { &self.core }
    fn core_mut(&mut self) -> &mut Core { &mut self.core }

    fn init(core: Core, flags: Self::Flags) -> (Self, Task<Message>) {
        let (toplevels, reverse, generation, theme_preset) = flags;
        let n = toplevels.len();
        let selected = if reverse {
            n.saturating_sub(1)
        } else {
            1.min(n.saturating_sub(1))
        };

        let theme = theme_preset.values();
        // Pre-resolve icons and labels once before surface creation so view() never hits disk
        let visuals: Vec<AppVisual> = toplevels
            .iter()
            .map(|entry| visual_for(&entry.app_id, &entry.title, theme.icon_size))
            .collect();

        let (surface_w, surface_h) = crate::ui::surface_size(toplevels.len(), &theme);

        let surface_id = WindowId::unique();
        let layer_task = get_layer_surface::<cosmic::Action<Message>>(SctkLayerSurfaceSettings {
            id: surface_id,
            layer: Layer::Overlay,
            keyboard_interactivity: KeyboardInteractivity::Exclusive,
            anchor: Anchor::empty(),
            size: Some((Some(surface_w), Some(surface_h))),
            ..Default::default()
        });

        // Wait 28ms for Wayland configure handshake & wgpu buffer stride stabilization
        // Also acts as a fast-switch grace period so sub-28ms Alt+Tab never flashes on screen
        let ready_task = Task::perform(
            async { tokio::time::sleep(Duration::from_millis(28)).await; },
            |_| cosmic::Action::App(Message::Ready),
        );

        (
            AppSwitcher {
                core,
                toplevels,
                visuals,
                selected,
                generation,
                finishing: false,
                ready: false,
                super_held: false,
                alt_held: true,
                surface_id,
                theme,
            },
            Task::batch([layer_task, ready_task]),
        )
    }

    fn update(&mut self, msg: Message) -> Task<Message> {
        if self.finishing { return Task::none(); }
        let n = self.toplevels.len();
        if n == 0 { return iced::exit(); }
        match msg {
            Message::Ready => {
                self.ready = true;
            }
            Message::SelectNext => {
                self.selected = (self.selected + 1) % n;
            }
            Message::SelectPrev => {
                self.selected = (self.selected + n - 1) % n;
            }
            Message::SelectIndex(i) => {
                if i < n { self.selected = i; }
            }
            Message::Activate => {
                self.finishing = true;
                self.ready = false;
                let _ = std::fs::remove_file(crate::socket_path());
                if let Err(error) = crate::wayland::activate(
                    &self.generation, self.toplevels[self.selected].handle_key,
                ) {
                    log::error!("Could not activate selected window: {error:#}");
                }
                return Task::batch([
                    destroy_layer_surface(self.surface_id),
                    iced::exit(),
                ]);
            }
            Message::Cancel => {
                self.finishing = true;
                self.ready = false;
                let _ = std::fs::remove_file(crate::socket_path());
                return Task::batch([
                    destroy_layer_surface(self.surface_id),
                    iced::exit(),
                ]);
            }
            Message::KeyEvent(ke) => match ke {
                keyboard::Event::KeyPressed { key, modifiers, .. } => match key {
                    iced::keyboard::Key::Named(Named::Tab) => {
                        return self.update(if modifiers.shift() {
                            Message::SelectPrev
                        } else {
                            Message::SelectNext
                        });
                    }
                    iced::keyboard::Key::Named(Named::ArrowRight) | iced::keyboard::Key::Named(Named::ArrowDown) => {
                        return self.update(Message::SelectNext);
                    }
                    iced::keyboard::Key::Named(Named::ArrowLeft) | iced::keyboard::Key::Named(Named::ArrowUp) => {
                        return self.update(Message::SelectPrev);
                    }
                    iced::keyboard::Key::Named(Named::Escape) => {
                        return self.update(Message::Cancel);
                    }
                    iced::keyboard::Key::Named(Named::Enter) => {
                        return self.update(Message::Activate);
                    }
                    _ => {}
                },
                keyboard::Event::KeyReleased { key, .. } => match key {
                    iced::keyboard::Key::Named(Named::Alt)
                    | iced::keyboard::Key::Named(Named::AltGraph)
                    | iced::keyboard::Key::Named(Named::Super) => {
                        return self.update(Message::Activate);
                    }
                    _ => {}
                },
                keyboard::Event::ModifiersChanged(mods) => {
                    if !mods.alt() && !mods.logo() {
                        return self.update(Message::Activate);
                    }
                    self.super_held = mods.logo();
                    self.alt_held = mods.alt();
                }
            },
        }
        Task::none()
    }

    fn subscription(&self) -> Subscription<Message> {
        let key_sub = event::listen_with(|event, _status, _window| {
            match event {
                Event::Keyboard(ke) => Some(Message::KeyEvent(ke)),
                Event::Window(iced::window::Event::Unfocused) => Some(Message::Cancel),
                _ => None,
            }
        });

        let socket_sub = {
            use std::any::TypeId;
            use cosmic::iced::futures::SinkExt;
            struct SocketSub;
            Subscription::run_with(TypeId::of::<SocketSub>(), |_| {
                cosmic::iced::stream::channel(16, |mut tx: cosmic::iced::futures::channel::mpsc::Sender<Message>| async move {
                    use tokio::io::AsyncReadExt;
                    let listener = tokio::net::UnixListener::from_std(
                        crate::UI_LISTENER.get().expect("UI socket initialized").try_clone().expect("clone UI socket")
                    ).expect("nonblocking UI socket");
                    loop {
                        if let Ok((mut stream, _)) = listener.accept().await {
                            let mut buf = Vec::new();
                            let read = tokio::time::timeout(std::time::Duration::from_secs(1),
                                (&mut stream).take(16).read_to_end(&mut buf)).await;
                            if !matches!(read, Ok(Ok(_))) { continue; }
                            let msg = match buf.as_slice() {
                                b"next" => Message::SelectNext,
                                b"prev" => Message::SelectPrev,
                                _ => continue,
                            };
                            let _ = tx.send(msg).await;
                        }
                    }
                })
            })
        };

        Subscription::batch([key_sub, socket_sub])
    }

    fn view(&self) -> Element<'_, Message> {
        crate::ui::view(self)
    }

    fn view_window(&self, _id: WindowId) -> Element<'_, Message> {
        crate::ui::view(self)
    }
}

pub fn run(
    toplevels: Vec<ToplevelEntry>,
    reverse: bool,
    generation: String,
    theme: Theme,
) -> Result<()> {
    let settings = Settings::default()
        .no_main_window(true)
        .transparent(true);
    cosmic::app::run::<AppSwitcher>(settings, (toplevels, reverse, generation, theme))
        .map_err(|e| anyhow::anyhow!("{e:?}"))
}



use cosmic::widget::icon;
use freedesktop_desktop_entry::{DesktopEntry, Iter as DesktopIter};
use std::collections::HashSet;
use std::path::{Path, PathBuf};

const FALLBACK_ICON: &str = "application-x-executable";

pub enum AppIcon {
    Named(String),
    File(PathBuf),
}

pub struct AppVisual {
    pub icon: AppIcon,
    pub label: String,
}

pub fn visual_for(app_id: &str, window_title: &str, size: u16) -> AppVisual {
    if app_id.starts_with("steam_app_") {
        return AppVisual {
            icon: resolve("steam", size),
            label: first_non_empty(&[window_title, "Steam"]).to_string(),
        };
    }

    let entry = desktop_entry_for(app_id);
    let label = entry.as_ref()
        .and_then(|e| e.name.as_deref())
        .filter(|n| !n.is_empty())
        .unwrap_or_else(|| first_non_empty(&[window_title, app_id, "Unknown"]))
        .to_string();

    let icon = match entry.and_then(|e| e.icon) {
        Some(field) if Path::new(&field).is_absolute() && Path::new(&field).is_file() => {
            AppIcon::File(PathBuf::from(field))
        }
        Some(field) => resolve(&icon_name_from_field(&field), size),
        None => resolve(app_id.split('.').next_back().unwrap_or(app_id), size),
    };

    AppVisual { icon, label }
}

fn first_non_empty<'a>(candidates: &[&'a str]) -> &'a str {
    candidates.iter().copied().find(|c| !c.is_empty()).unwrap_or_default()
}

fn resolve(name: &str, size: u16) -> AppIcon {
    if icon::from_name(name).size(size).path().is_some() {
        return AppIcon::Named(name.to_string());
    }
    log::debug!("icon {name:?} not found at size {size}, falling back to {FALLBACK_ICON}");
    AppIcon::Named(FALLBACK_ICON.to_string())
}

struct DesktopInfo {
    icon: Option<String>,
    name: Option<String>,
}

fn desktop_entry_for(app_id: &str) -> Option<DesktopInfo> {
    if app_id.is_empty() {
        return None;
    }
    let dirs = search_dirs();

    for dir in &dirs {
        if let Some(info) = read_entry(&dir.join(format!("{app_id}.desktop"))) {
            return Some(info);
        }
    }

    for path in DesktopIter::new(dirs.clone()) {
        let Ok(bytes) = std::fs::read(&path) else { continue };
        let Ok(s) = std::str::from_utf8(&bytes) else { continue };
        let Ok(entry) = DesktopEntry::decode(&path, s) else { continue };
        let stem = path.file_stem().and_then(|s| s.to_str()).unwrap_or_default();
        let claims = entry.startup_wm_class().is_some_and(|c| c.eq_ignore_ascii_case(app_id))
            || stem_matches(stem, app_id);
        if claims {
            return Some(DesktopInfo {
                icon: entry.icon().map(ToString::to_string),
                name: entry.name(None).map(|n| n.to_string()),
            });
        }
    }

    log::debug!("no .desktop entry found for app_id {app_id:?}");
    None
}

fn stem_matches(stem: &str, app_id: &str) -> bool {
    stem.eq_ignore_ascii_case(app_id)
        || stem.rsplit('.').next().is_some_and(|last| last.eq_ignore_ascii_case(app_id))
}

fn read_entry(path: &Path) -> Option<DesktopInfo> {
    let bytes = std::fs::read(path).ok()?;
    let s = std::str::from_utf8(&bytes).ok()?;
    let entry = DesktopEntry::decode(path, s).ok()?;
    Some(DesktopInfo {
        icon: entry.icon().map(ToString::to_string),
        name: entry.name(None).map(|n| n.to_string()),
    })
}

fn search_dirs() -> Vec<PathBuf> {
    let home = std::env::var("HOME").unwrap_or_default();
    let data_home = std::env::var("XDG_DATA_HOME")
        .ok()
        .filter(|d| !d.is_empty())
        .unwrap_or_else(|| format!("{home}/.local/share"));
    let data_dirs = std::env::var("XDG_DATA_DIRS")
        .ok()
        .filter(|d| !d.is_empty())
        .unwrap_or_else(|| "/usr/local/share:/usr/share".to_string());

    let xdg = std::iter::once(data_home.clone())
        .chain(data_dirs.split(':').map(ToString::to_string))
        .filter(|d| !d.is_empty())
        .map(|d| PathBuf::from(d).join("applications"));

    let extra = [
        PathBuf::from("/var/lib/flatpak/exports/share/applications"),
        PathBuf::from(format!("{data_home}/flatpak/exports/share/applications")),
        PathBuf::from("/var/lib/snapd/desktop/applications"),
    ];

    let mut seen = HashSet::new();
    xdg.chain(extra).filter(|d| seen.insert(d.clone())).collect()
}

fn icon_name_from_field(icon: &str) -> String {
    if icon.starts_with('/') {
        Path::new(icon)
            .file_stem()
            .and_then(|s| s.to_str())
            .unwrap_or(icon)
            .to_string()
    } else {
        icon.to_string()
    }
}

#[derive(Serialize, Deserialize)]
enum Request {
    List(WorkspaceScope),
    Activate { generation: String, key: u64 },
    Ping,
}

#[derive(Serialize, Deserialize)]
enum Response {
    List(Snapshot),
    Ok,
    Error(String),
}

pub fn daemon_socket_path() -> Result<std::path::PathBuf> {
    Ok(crate::runtime_dir()?.join("cosmic-ext-app-switcher-mru.sock"))
}

fn request(request: &Request) -> Result<Response> {
    let mut stream = UnixStream::connect(daemon_socket_path()?)
        .context("MRU service is not running. Run: systemctl --user restart cosmic-ext-app-switcher-mru.service")?;
    stream.set_read_timeout(Some(Duration::from_secs(2)))?;
    stream.set_write_timeout(Some(Duration::from_secs(2)))?;
    serde_json::to_writer(&mut stream, request)?;
    stream.shutdown(std::net::Shutdown::Write)?;
    let mut bytes = Vec::new();
    stream.take(4 * 1024 * 1024).read_to_end(&mut bytes)?;
    let reply: Response = serde_json::from_slice(&bytes)?;
    if let Response::Error(message) = &reply {
        return Err(anyhow!("{message}"));
    }
    Ok(reply)
}

pub fn snapshot(scope: WorkspaceScope) -> Result<Snapshot> {
    match request(&Request::List(scope))? {
        Response::List(snapshot) => Ok(snapshot),
        _ => Err(anyhow!("Unexpected MRU service response")),
    }
}

pub fn activate(generation: &str, key: u64) -> Result<()> {
    match request(&Request::Activate { generation: generation.into(), key })? {
        Response::Ok => Ok(()),
        _ => Err(anyhow!("Unexpected MRU activation response")),
    }
}

pub fn ping() -> Result<()> {
    match request(&Request::Ping)? {
        Response::Ok => Ok(()),
        _ => Err(anyhow!("Unexpected MRU health response")),
    }
}

const TOPLEVEL_INFO_VERSION:    u32 = 1;
const TOPLEVEL_MANAGER_VERSION: u32 = 1;
const SEAT_VERSION:             u32 = 7;

const REQUIRED_GLOBALS: &[(&str, u32)] = &[
    ("zcosmic_toplevel_info_v1",    TOPLEVEL_INFO_VERSION),
    ("zcosmic_toplevel_manager_v1", TOPLEVEL_MANAGER_VERSION),
    ("zwlr_layer_shell_v1",         1),
    ("wl_seat",                     SEAT_VERSION),
];

pub struct GlobalStatus {
    interface:  &'static str,
    needed:     u32,
    advertised: Option<u32>,
}

impl GlobalStatus {
    pub fn ok(&self) -> bool {
        self.advertised.is_some_and(|v| v >= self.needed)
    }
}

impl std::fmt::Display for GlobalStatus {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        let (interface, needed) = (self.interface, self.needed);
        match self.advertised {
            Some(v) if v >= needed => write!(f, "{interface}: ok (v{v}, needs v{needed})"),
            Some(v) => write!(f, "{interface}: TOO OLD (v{v}, needs v{needed})"),
            None    => write!(f, "{interface}: NOT offered (needs v{needed})"),
        }
    }
}

fn required_globals_status(advertised: &[(String, u32)]) -> Vec<GlobalStatus> {
    REQUIRED_GLOBALS.iter()
        .map(|&(interface, needed)| GlobalStatus {
            interface,
            needed,
            advertised: advertised.iter()
                .filter(|(i, _)| i == interface)
                .map(|&(_, v)| v)
                .max(),
        })
        .collect()
}

pub fn probe_required_globals() -> Result<Vec<GlobalStatus>> {
    let conn = Connection::connect_to_env()
        .context("could not connect to the Wayland compositor (is COSMIC running?)")?;
    let (globals, _queue) = registry_queue_init::<RegistryProbe>(&conn)?;
    let advertised: Vec<(String, u32)> = globals.contents().clone_list()
        .into_iter()
        .map(|g| (g.interface, g.version))
        .collect();
    Ok(required_globals_status(&advertised))
}

pub fn run_daemon() -> Result<()> {
    let _lock = crate::file_lock("cosmic-ext-app-switcher-mru.lock", true)?;
    let conn    = Connection::connect_to_env()?;
    let display = conn.display();
    let mut queue = conn.new_event_queue();
    let qh = queue.handle();

    let registry = display.get_registry(&qh, ());

    let mut data = AppData {
        history: History::default(),
        next_key: 0,
        generation: format!("{}-{}", std::process::id(), SystemTime::now().duration_since(UNIX_EPOCH)?.as_nanos()),
        toplevels: vec![],
        _info: None,
        manager: None,
        seat: None,
        _workspace_manager: None,
        outputs: vec![],
        toplevel_info_name: None,
        globals: vec![],
    };

    queue.roundtrip(&mut data)?;

    let missing: Vec<String> = required_globals_status(&data.globals).iter()
        .filter(|s| !s.ok())
        .map(ToString::to_string)
        .collect();
    if !missing.is_empty() {
        return Err(anyhow!(
            "cosmic-ext-app-switcher can't run: the compositor doesn't offer the Wayland \
             interfaces it needs ({}). Run `cosmic-ext-app-switcher --check-compat` for details.",
            missing.join("; "),
        ));
    }

    queue.roundtrip(&mut data)?;

    if let Some(name) = data.toplevel_info_name.take() {
        data._info = Some(
            registry.bind::<ZcosmicToplevelInfoV1, _, _>(name, TOPLEVEL_INFO_VERSION, &qh, ())
        );
    }

    for _ in 0..5 {
        queue.roundtrip(&mut data)?;
    }

    let path = daemon_socket_path()?;
    let _ = std::fs::remove_file(&path);
    let listener = UnixListener::bind(&path)?;
    std::fs::set_permissions(&path, std::fs::Permissions::from_mode(0o600))?;
    listener.set_nonblocking(true)?;
    let _cleanup = crate::SocketCleanup(path);
    log::info!("MRU service ready; history starts now");

    loop {
        queue.dispatch_pending(&mut data)?;
        conn.flush()?;
        let Some(guard) = queue.prepare_read() else { continue; };
        let mut fds = [
            libc::pollfd { fd: conn.backend().poll_fd().as_raw_fd(), events: libc::POLLIN, revents: 0 },
            libc::pollfd { fd: listener.as_raw_fd(), events: libc::POLLIN, revents: 0 },
        ];
        let ready = unsafe { libc::poll(fds.as_mut_ptr(), fds.len() as libc::nfds_t, -1) };
        if ready < 0 {
            drop(guard);
            let error = std::io::Error::last_os_error();
            if error.kind() == std::io::ErrorKind::Interrupted { continue; }
            return Err(error.into());
        }
        if fds[0].revents != 0 {
            guard.read()?;
            queue.dispatch_pending(&mut data)?;
        } else {
            drop(guard);
        }
        if fds[1].revents & libc::POLLIN != 0 {
            let (mut stream, _) = listener.accept()?;
            stream.set_read_timeout(Some(Duration::from_millis(500)))?;
            stream.set_write_timeout(Some(Duration::from_millis(500)))?;
            let mut bytes = Vec::new();
            if (&mut stream).take(65536).read_to_end(&mut bytes).is_err() { continue; }
            let reply = match serde_json::from_slice::<Request>(&bytes) {
                Ok(Request::List(scope)) => {
                    queue.roundtrip(&mut data)?;
                    Response::List(data.snapshot(scope))
                }
                Ok(Request::Activate { generation, key }) => {
                    queue.roundtrip(&mut data)?;
                    if generation != data.generation {
                        Response::Error("MRU service restarted; reopen Alt+Tab".into())
                    } else if let Some(t) = data.toplevels.iter().find(|t| t.key == key) {
                        if let (Some(manager), Some(seat)) = (&data.manager, &data.seat) {
                            manager.activate(&t.handle, seat);
                            queue.roundtrip(&mut data)?;
                            Response::Ok
                        } else {
                            Response::Error("Activation protocol unavailable".into())
                        }
                    } else {
                        Response::Error("Selected window has already closed".into())
                    }
                }
                Ok(Request::Ping) => Response::Ok,
                Err(error) => Response::Error(error.to_string()),
            };
            let _ = serde_json::to_writer(&mut stream, &reply);
            let _ = stream.flush();
        }
    }
}

impl AppData {
    fn snapshot(&self, scope: WorkspaceScope) -> Snapshot {
        let reference = self.toplevels.iter()
            .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
            .min_by_key(|t| self.history.sort_key(t.key));
        let active_outputs = reference.map(|t| t.outputs.as_slice()).unwrap_or(&[]);
        let mut entries: Vec<_> = self.toplevels.iter()
            .filter(|t| !t.app_id.is_empty() || !t.title.is_empty())
            .filter(|t| match scope {
                WorkspaceScope::AllWorkspaces => true,
                WorkspaceScope::CurrentWorkspace => true,
                WorkspaceScope::CurrentOutput => active_outputs.is_empty()
                    || t.outputs.iter().any(|o| active_outputs.contains(o)),
            })
            .map(|t| ToplevelEntry {
                app_id: t.app_id.clone(),
                title: t.title.clone(),
                is_active: t.is_active,
                handle_key: t.key,
            }).collect();
        entries.sort_by_key(|t| self.history.sort_key(t.handle_key));
        Snapshot { generation: self.generation.clone(), toplevels: entries }
    }
}

impl Dispatch<wl_registry::WlRegistry, ()> for AppData {
    fn event(
        data: &mut Self,
        registry: &wl_registry::WlRegistry,
        event: wl_registry::Event,
        _: &(),
        _: &Connection,
        qh: &QueueHandle<Self>,
    ) {
        if let wl_registry::Event::Global { name, interface, version } = event {
            data.globals.push((interface.clone(), version));
            match interface.as_str() {
                "zcosmic_toplevel_info_v1" if version >= TOPLEVEL_INFO_VERSION => {
                    data.toplevel_info_name = Some(name);
                }
                "zcosmic_toplevel_manager_v1" if version >= TOPLEVEL_MANAGER_VERSION => {
                    data.manager = Some(registry.bind::<ZcosmicToplevelManagerV1, _, _>(
                        name, TOPLEVEL_MANAGER_VERSION, qh, (),
                    ));
                }
                "wl_seat" if version >= SEAT_VERSION => {
                    if data.seat.is_none() {
                        data.seat = Some(
                            registry.bind::<wl_seat::WlSeat, _, _>(name, SEAT_VERSION, qh, ())
                        );
                    }
                }
                "wl_output" => {
                    data.outputs.push(
                        registry.bind::<wl_output::WlOutput, _, _>(name, 1, qh, ())
                    );
                }
                "zcosmic_workspace_manager_v1" => {
                    data._workspace_manager = Some(
                        registry.bind::<ZcosmicWorkspaceManagerV1, _, _>(name, 1, qh, ())
                    );
                }
                _ => {}
            }
        }
    }
}

impl Dispatch<ZcosmicToplevelInfoV1, ()> for AppData {
    fn event(
        data: &mut Self,
        _: &ZcosmicToplevelInfoV1,
        event: zcosmic_toplevel_info_v1::Event,
        _: &(),
        _: &Connection,
        _: &QueueHandle<Self>,
    ) {
        if let zcosmic_toplevel_info_v1::Event::Toplevel { toplevel } = event {
            data.next_key += 1;
            data.history.open(data.next_key);
            data.toplevels.push(Toplevel {
                key: data.next_key,
                handle:     toplevel,
                app_id:     String::new(),
                title:      String::new(),
                is_active:  false,
                outputs:    vec![],
                workspaces: vec![],
            });
        }
    }

    event_created_child!(AppData, ZcosmicToplevelInfoV1, [
        zcosmic_toplevel_info_v1::EVT_TOPLEVEL_OPCODE =>
            (ZcosmicToplevelHandleV1, ()),
    ]);
}

impl Dispatch<ZcosmicToplevelHandleV1, ()> for AppData {
    fn event(
        data: &mut Self,
        handle: &ZcosmicToplevelHandleV1,
        event: zcosmic_toplevel_handle_v1::Event,
        _: &(),
        _: &Connection,
        _: &QueueHandle<Self>,
    ) {
        let Some(t) = data.toplevels.iter_mut().find(|t| &t.handle == handle) else {
            return;
        };
        match event {
            zcosmic_toplevel_handle_v1::Event::AppId { app_id } => {
                t.app_id = app_id;
            }
            zcosmic_toplevel_handle_v1::Event::Title { title } => {
                t.title = title;
            }
            zcosmic_toplevel_handle_v1::Event::State { state } => {
                let activated = zcosmic_toplevel_handle_v1::State::Activated as u32;
                t.is_active = state
                    .chunks_exact(4)
                    .any(|b| u32::from_ne_bytes(b.try_into().unwrap()) == activated);
                data.history.state(t.key, t.is_active);
            }
            zcosmic_toplevel_handle_v1::Event::Closed => {
                data.history.close(t.key);
                data.toplevels.retain(|t| &t.handle != handle);
            }
            zcosmic_toplevel_handle_v1::Event::OutputEnter { output } => {
                if !t.outputs.contains(&output) {
                    t.outputs.push(output);
                }
            }
            zcosmic_toplevel_handle_v1::Event::OutputLeave { output } => {
                t.outputs.retain(|o| o != &output);
            }
            zcosmic_toplevel_handle_v1::Event::WorkspaceEnter { workspace } => {
                if !t.workspaces.contains(&workspace) {
                    t.workspaces.push(workspace);
                }
            }
            zcosmic_toplevel_handle_v1::Event::WorkspaceLeave { workspace } => {
                t.workspaces.retain(|w| w != &workspace);
            }
            _ => {}
        }
    }
}

#[cfg(test)]
mod tests {
    use super::required_globals_status;

    fn advertised(globals: &[(&str, u32)]) -> Vec<(String, u32)> {
        globals.iter().map(|&(i, v)| (i.to_string(), v)).collect()
    }

    fn line_for(globals: &[(&str, u32)], interface: &str) -> String {
        required_globals_status(&advertised(globals)).iter()
            .map(ToString::to_string)
            .find(|l| l.starts_with(&format!("{interface}:")))
            .unwrap()
    }

    #[test]
    fn everything_offered_is_ok() {
        let globals = [
            ("zcosmic_toplevel_info_v1", 3),
            ("zcosmic_toplevel_manager_v1", 4),
            ("zwlr_layer_shell_v1", 5),
            ("wl_seat", 9),
        ];
        assert!(required_globals_status(&advertised(&globals)).iter().all(|s| s.ok()));
    }

    #[test]
    fn missing_global_is_reported() {
        let globals = [("zcosmic_toplevel_info_v1", 3), ("zwlr_layer_shell_v1", 5), ("wl_seat", 9)];
        let statuses = required_globals_status(&advertised(&globals));
        assert_eq!(statuses.iter().filter(|s| !s.ok()).count(), 1);
        assert_eq!(
            line_for(&globals, "zcosmic_toplevel_manager_v1"),
            "zcosmic_toplevel_manager_v1: NOT offered (needs v1)",
        );
    }

    #[test]
    fn version_below_the_one_we_bind_is_too_old() {
        let globals = [("wl_seat", 5)];
        assert_eq!(line_for(&globals, "wl_seat"), "wl_seat: TOO OLD (v5, needs v7)");
    }

    #[test]
    fn repeated_global_uses_highest_version() {
        let globals = [("wl_seat", 5), ("wl_seat", 8)];
        assert_eq!(line_for(&globals, "wl_seat"), "wl_seat: ok (v8, needs v7)");
    }
}



#!/usr/bin/env python3
"""COSMIC Alt+Tab MRU reusable source installer (Anti-Flicker Edition).

Spusteni instalace ze slozky projektu (BEZ sudo):
  python3 install.py

Obnoveni predchozi zalohy:
  python3 install.py --rollback
"""
import argparse
import datetime
import fcntl
import json
import os
from pathlib import Path
import shutil
import subprocess
import sys
import tempfile
import time

SERVICE = 'cosmic-ext-app-switcher-mru.service'
BASE = Path.home() / '.local/share/cosmic-alt-tab-mru'
BIN = Path.home() / '.local/bin/cosmic-ext-app-switcher'
CONFIG = Path(os.environ.get('XDG_CONFIG_HOME', str(Path.home() / '.config')))
UNIT = CONFIG / 'systemd/user' / SERVICE
START = Path.home() / '.local/bin/cosmic-ext-app-switcher-mru-start'
AUTOSTART = CONFIG / 'autostart/cosmic-ext-app-switcher-mru.desktop'
PROJECT_DIR = Path(__file__).resolve().parent


def run(argv, **kwargs):
    return subprocess.run([str(x) for x in argv], check=True, **kwargs)


def status():
    return subprocess.run(['systemctl', '--user', 'is-active', '--quiet', SERVICE]).returncode == 0


def atomic_bytes(path, data, mode):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(prefix='.' + path.name + '.', dir=path.parent)
    try:
        with os.fdopen(fd, 'wb') as output:
            output.write(data)
            output.flush()
            os.fsync(output.fileno())
        os.chmod(tmp, mode)
        os.replace(tmp, path)
    finally:
        if os.path.lexists(tmp):
            os.unlink(tmp)


def backup(paths):
    folder = BASE / 'backups' / datetime.datetime.now().strftime('%Y%m%d-%H%M%S-%f')
    folder.mkdir(parents=True, mode=0o700)
    items = []
    for i, target in enumerate(paths):
        item = {'path': str(target), 'kind': 'missing'}
        if target.is_symlink():
            item.update(kind='symlink', link=os.readlink(target))
        elif target.is_file():
            name = str(i) + '.backup'
            shutil.copy2(target, folder / name)
            item.update(kind='file', file=name, mode=target.stat().st_mode & 0o777)
        elif target.exists():
            raise RuntimeError(f'Neocekavany typ cile: {target}')
        items.append(item)
    manifest = {'items': items, 'service_was_active': status()}
    (folder / 'manifest.json').write_text(json.dumps(manifest, indent=2), encoding='utf-8')
    return folder


def restore(folder):
    manifest = json.loads((folder / 'manifest.json').read_text(encoding='utf-8'))
    expected = {str(x) for x in [BIN, UNIT, START, AUTOSTART]}
    if {item['path'] for item in manifest['items']} != expected:
        raise RuntimeError('Zaloha neodpovida teto instalaci.')
    for item in manifest['items']:
        if item['kind'] == 'file' and not (folder / item['file']).is_file():
            raise RuntimeError('V zaloze chybi soubor; obnova nebyla zahajena.')
    subprocess.run(['systemctl', '--user', 'stop', SERVICE], check=False)
    for item in manifest['items']:
        target = Path(item['path'])
        if item['kind'] == 'file':
            atomic_bytes(target, (folder / item['file']).read_bytes(), item['mode'])
        elif item['kind'] == 'symlink':
            target.unlink(missing_ok=True)
            target.symlink_to(item['link'])
        else:
            target.unlink(missing_ok=True)
    run(['systemctl', '--user', 'daemon-reload'])
    if manifest['service_was_active']:
        run(['systemctl', '--user', 'start', SERVICE])
    print('Predchozi instalace byla obnovena.', flush=True)


def import_environment():
    names = [name for name in ['WAYLAND_DISPLAY', 'DISPLAY', 'XDG_CURRENT_DESKTOP', 'XDG_SESSION_TYPE'] if name in os.environ]
    if names:
        run(['systemctl', '--user', 'import-environment', *names])


def desktop_quote(value):
    value = value.replace('%', '%%')
    for character in ['\\', '"', '`', '$']:
        value = value.replace(character, '\\' + character)
    value = value.replace('\\', '\\\\')
    return '"' + value + '"'


def install(source_dir: Path):
    if os.geteuid() == 0:
        raise RuntimeError('Spust instalator jako svuj bezny uzivatel, BEZ sudo.')
    if not os.environ.get('WAYLAND_DISPLAY') or not os.environ.get('XDG_RUNTIME_DIR'):
        raise RuntimeError('Spust instalator v terminalu uvnitr prihlaseneho COSMIC.')
    if not (source_dir / 'Cargo.toml').is_file():
        raise RuntimeError(f'Ve slozce {source_dir} chybi Cargo.toml.')

    cargo = shutil.which('cargo')
    if not cargo and (Path.home() / '.cargo/bin/cargo').is_file():
        cargo = str(Path.home() / '.cargo/bin/cargo')
    if not cargo:
        raise RuntimeError('Chybi cargo/Rust.')

    env = os.environ.copy()
    env['PATH'] = str(Path(cargo).parent) + os.pathsep + env.get('PATH', '')
    env['CARGO_TARGET_DIR'] = str(Path.home() / '.cache/cosmic-alt-tab-mru/target')
    env.setdefault('CARGO_BUILD_JOBS', '4')

    print(f'1/3 Kompiluji a testuji ze slozky: {source_dir}', flush=True)
    run([cargo, 'test', '--locked', '--bin', 'cosmic-ext-app-switcher'], cwd=source_dir, env=env)
    run([cargo, 'build', '--locked', '--release', '--bin', 'cosmic-ext-app-switcher'], cwd=source_dir, env=env)
    new_binary = Path(env['CARGO_TARGET_DIR']) / 'release/cosmic-ext-app-switcher'
    run([new_binary, '--check-compat'])

    print('2/3 Vytvarim zalohu a instaluji prepinac.', flush=True)
    folder = backup([BIN, UNIT, START, AUTOSTART])
    try:
        subprocess.run(['systemctl', '--user', 'stop', SERVICE], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        atomic_bytes(BIN, new_binary.read_bytes(), 0o755)
        unit = '''[Unit]
Description=COSMIC Alt-Tab per-window MRU history
PartOf=graphical-session.target
After=graphical-session.target

[Service]
Type=simple
ExecStart="%h/.local/bin/cosmic-ext-app-switcher" --daemon
Restart=on-failure
RestartSec=2
UMask=0077
'''
        atomic_bytes(UNIT, unit.encode(), 0o644)
        starter = '''#!/bin/sh
set -eu
[ -n "${WAYLAND_DISPLAY:-}" ] || exit 0
systemctl --user import-environment WAYLAND_DISPLAY
[ -z "${DISPLAY:-}" ] || systemctl --user import-environment DISPLAY
systemctl --user restart cosmic-ext-app-switcher-mru.service
'''
        atomic_bytes(START, starter.encode(), 0o755)
        desktop = '[Desktop Entry]\nType=Application\nName=COSMIC Alt-Tab MRU history\nExec=' + desktop_quote(str(START)) + '\nTerminal=false\nOnlyShowIn=COSMIC;\n'
        atomic_bytes(AUTOSTART, desktop.encode(), 0o644)
        run(['systemctl', '--user', 'daemon-reload'])
        import_environment()
        run(['systemctl', '--user', 'start', SERVICE])

        print('3/3 Kontroluji spojeni s MRU sluzbou.', flush=True)
        deadline = time.monotonic() + 15
        while True:
            result = subprocess.run([BIN, '--mru-check'], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
            if result.returncode == 0:
                break
            if time.monotonic() >= deadline:
                raise RuntimeError('Sluzba se nespustila; obnovuji puvodni instalaci.')
            time.sleep(0.2)
        atomic_bytes(BASE / 'last-backup', (str(folder) + '\n').encode(), 0o600)
    except BaseException:
        restore(folder)
        raise

    print('\nHOTOVO. Prepinac je nainstalovany a sluzba bezi.')


def main():
    parser = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    parser.add_argument('--rollback', action='store_true', help='Obnovi predchozi zalohu')
    parser.add_argument('--source', type=Path, default=PROJECT_DIR, help='Cesta ke slozce s Cargo.toml')
    args = parser.parse_args()

    BASE.mkdir(parents=True, exist_ok=True)
    with (BASE / 'installer.lock').open('a') as lock:
        fcntl.flock(lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
        if args.rollback:
            marker = BASE / 'last-backup'
            if not marker.is_file():
                raise RuntimeError('Nebyla nalezena zaloha z uspesne instalace.')
            restore(Path(marker.read_text().strip()))
            marker.unlink()
        else:
            install(args.source.resolve())


if __name__ == '__main__':
    try:
        main()
    except (Exception, KeyboardInterrupt) as error:
        print('\nChyba:', error, file=sys.stderr)
        raise SystemExit(1)
